# r88 Conditional power calculation

Six conditional flat true-attack additions are now explicitly registered from MHDB Japanese skill rank descriptions retrieved 2026-10-07: Agitator, Peak Performance, Resentment, Adrenaline Rush, Counterstrike, Foray. The source snapshot is evidence/conditional-attack-mhdb-20261007.json. Skill values are capped to registered rank, and malformed levels are pending.

Normal retains existing unconditional calculated stats. Maximum reference adds registered flat amounts to calculated true attack and uses maximum affinity. This additive order is a reference convention, not a validated all-skills stacking-order implementation. Current elemental stats remain unchanged. The applied skills and excluded alternatives are retained in report/AI data and visible under comparison tables. Peak Performance and Resentment cannot share a health state: use the higher applicable addition rather than their sum.

If an explicitly catalogued unresolved damage condition is equipped, NORMAL remains available but MAXIMUM is null. These include Offensive Guard, Coalescence, Element Absorption, Convert Element, Heroics, Fortify, Ambush, Slicing Shot, Wet Blade Mark, listed series effects and Critical Draw hit-state handling. This catalogue is not complete; unknown skills must be audited before claiming full skill coverage. Dedicated weapon handlers and elemental critical still retain r87 gates. Full maximum attack/element/state coverage remains incomplete.

User-provided Burst source: https://gamewith.jp/mhwilds/486597 (updated 2026-09-08, read 2026-10-07). STANDARD_BURST_SOURCE holds fourteen weapon kinds grouped by equal per-level five-hit totals. The totals include the initial hit bonus; do not add initial +5 or its elemental bonus again. MAXIMUM assumes the five-hit buff was activated before the STANDARD route. NORMAL stays inactive; this does not implement mid-route activation or expiry. Element is added only for an actual nonzero fire/water/thunder/ice/dragon weapon, never raw/status. Bowgun element cells are absent in the source and explicitly not applicable, rather than a generic elemental-ammo formula. Dedicated bow/bowgun/etc damage remains gated. Source status is SOURCE_CONFIRMED_NOT_GAME_VERIFIED; numeric data does not establish an observed game version. Stack-order verification remains outstanding. Conditional plan and UI retain attack/element additions and this preactivation assumption.

Maximum affinity bug fixed: calcBuild already passes affinity with unconditional Critical Eye; calcMaxAffinity no longer applies it again. WEX and other conditional affinity remain on maximum side.

UI and exports now permit a normal power index while maximum is pending. Both denominators remain selected baseline NORMAL and cross-weapon/profile comparison remains unavailable. No changes to absolute user combo DPS formulas or fixed comparison column geometry.
