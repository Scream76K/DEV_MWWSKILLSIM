# r115 Bow Bladescale Loading

## 確認結果

最終版の単体127件、DOM270件、ブラウザ42件、合計439件が成功（失敗0）。追加8項目は適用成分、通常／最大、3射撃、非対象ビン、スキル併用、不正入力、保留維持、見える前提表示を確認。実装前の失敗と実装後の成功を確認したテストを含む。独立レビューで重大・重要指摘なし。

初回の追加ブラウザテストは閉じた説明欄の本文をinnerTextで取得したため失敗。欄を実際に開く手順に直し、最終版の全ブラウザテストを再実行して成功。計算側の合格条件を緩めてはいない。

弓の刃鱗増装Lv1を、対応済みの固定STANDARD（溜め3・射撃→剛射→剛連射、14矢全命中）へ接続。

## 適用範囲

- 通常側：刃鱗ビン未発動。最大側：回避で得た強化3回分が残る発動直後を前提にした参考計算。
- 対応済みビンのうち接撃だけに、物理ダメージ1.25倍を一度適用。属性ダメージには適用しない。
- 強撃・ビンなしは非適用として計算し、結果に非適用状態を記録。睡眠ビンは資料上の対象だが、睡眠ビン自体のHP・蓄積計算は未実装のため対応を拡大しない。
- 固定3射撃として強化3回分を扱う。14矢のHitごとに残数を減らさない。残数・射撃単位の明細・補正をJSONへ記録。
- 回避成功率、再発動頻度、実戦の残弾、継続DPSは推測しない。異なる射撃順序への転用は拒否。
- 最大側の強化3回分の前提や、選択ビンが非適用であることは、折りたたみ条件欄だけでなく比較結果の計算状況にも表示。
- ファーストショット／フォースショットの併用は未接続のまま保留。
- 通常／最大の会心率、会心撃【属性】、チャージマスター、通常矢強化／剛射強化を既存の適用先で併用可能。未確定の条件付き属性倍率の順序は最大側のみ保留。
