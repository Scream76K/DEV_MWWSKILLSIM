# r85 — 装備比較結果のJSON保存・コピー

比較結果にJSON保存・コピー操作を追加する。
共通ダウンロード処理を利用し、コピーできない場合は画面にJSONを表示する。
自動送信やサーバーへの保存は追加しない。

## 出力内容

- 形式MHWildsBuildComparison、schemaVersion 1、リリース、基準ゲーム版。
- 選択した基準ビルドの位置・名前。
- 各ビルドの既存比較値、絶対DPS、DPS指数、増減率。
- 比較時の計算条件、コンボ、モンスター・部位の選択ID、比較日時。
- 参考計算であり実機検証済みを意味しないこと、食事等を取得していないこと。

未算出DPSはnull・NOT_CALCULATEDとし、その原因を推測しない。
算出済みDPSはREFERENCE_ONLY。未算出指数もnullのまま保持する。
書き出し時の現在入力値ではなく、比較実行時にコピーした条件を使用する。
出力は独立したスナップショットであり、編集しても比較キャッシュを変更しない。

コンボ・計算条件変更時には比較結果と条件キャッシュを解除する。
無効化後は古い結果を書き出さず、再比較を求める。
基準変更後は最新の基準で書き出す。画面回転は既存の比較結果と基準を維持する。

## 検証

新規DOM4件・モバイルChromium1件で、選択基準・null保持・スナップショットの不変性、
無効化、実際の比較実行での条件取得、ダウンロードJSONの内容を確認する。
今回のiPhone Safari実機確認は未実施。
