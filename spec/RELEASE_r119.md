# r119 — ヘビィ通常弾の追加参考比較

⑥の「ヘビィの通常弾・追加参考比較」で、弾Lv1〜3・距離・通常モード補正を共通条件として指定すると、通常弾1発分の3連射、全3Hitの参考ダメージを比較できます。基準列は通常側の実ダメージ、比較列と最大側は変化率と物理・属性寄与率を表示します。小数表示は1桁、内部計算は丸めません。

物理MV・Hit数は既存の技DBを参照し、距離・モード・通常弾強化Lv1の補正も新しい技DB参考レコードに置いています。計算モジュールにMVを複製しません。武器属性・斬れ味・破壊王を通常弾のHPダメージへ加算しません。正会心・負会心・通常と最大の会心率を分けて扱います。

この追加モードは比較用の共通条件を仮定する参考計算です。武器ごとの装填可否や実際のカスタマイズから自動取得しません。射撃位置が未接続のファーストショット／フォースショット装備時は通常・最大を保留します。未選択時は従来の属性弾STANDARDの保留を維持し、属性弾・ライト速射・竜熱特殊弾・コンボDPSを対応済みにしません。従来の固定STANDARD対応数8/14とは別に、対応状況JSONへ追加参考モードを記録します。

画面の比較と専用Handlerの比較APIで同じ計算を使用します。変更時に以前の比較・相談データを無効化します。過去の条件に新項目がなければ未選択へ戻し、弾Lv・距離・モードを推定しません。API実行後は編集中のビルド・比較条件・比較結果を復元します。

弓の貫通ビン1セット、強撃ビン3セットの実測を技DBの検証資料一覧へ追加しました。射撃順と合計表示の観測のみ採用し、スキル加算値・会心率・全STANDARDの実機照合済みには変更していません。強撃1セット目の2発目は3Hit、他は1Hitという違いも保持します。
