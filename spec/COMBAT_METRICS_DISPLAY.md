# 火力指標・コンボ評価の表示仕様（確定・最優先）

Status: ACCEPTED / 2026-10-08 / ユーザーによる3度目の明示的確認

## 絶対ルール

1. ビルドA単独・ビルドB単独・A/B比較の**すべて**において、主表示する「基準火力」「火力指数」「コンボ総ダメージ」「コンボDPS」は、正規化していない計算値とする。表示用にA=100へ変換しない。
2. 同一武器種のA/B比較では、A・B双方の**非正規化計算値**を主表示し、`(B/A - 1) × 100 %` の変化率を補助表示できる。A=100の相対指数を主表示しない。
3. コンボそのものの強さを判定できるよう、コンボ総ダメージ、所要時間、DPS（総ダメージ/所要時間）を別々に表示する。時間や技データが未検証ならDPSは未算出と理由を示し、推測で補完しない。
4. 異なる武器種間での優劣比較は、同等の検証条件が揃った**検証済みコンボDPSのみ**。火力指数、単発ダメージ、正規化指数による異武器種比較は禁止。
5. 「基準」とは比較に用いる実計算値を意味し、100という固定数値を意味しない。比較画面でも正規化値を火力指数と呼ばない。

## 表示例（仮定値）

- A: 基準火力 350.0、コンボ総ダメージ 1200.0、所要時間 6.0秒、DPS 200.0
- B: 基準火力 385.0、コンボ総ダメージ 1500.0、所要時間 10.0秒、DPS 150.0
- 比較の補助表示: 基準火力 +10.0%、DPS -25.0%。Aの主表示を100.0に置き換えない。

## 実装・回帰テストの受け入れ条件

- 単独表示と比較表示で同じビルドの火力計算値が一致すること。
- Aの選択を変更しても、各ビルドの非正規化火力・ダメージ・DPSの表示値は変化しないこと。変化してよいのは補助表示の増減率のみ。
- JSON出力にも非正規化値を保持し、増減率は別フィールドとすること。
- DPSが未検証なら数値を表示せず、未検証理由を示すこと。
- 異武器種比較の制限を保持すること。

## 既知の実装差分

r138のビルド比較UIには「基準100の火力指数」を主表示する箇所があり、本仕様と**不一致**。本仕様を正とし、次回のコード修正・回帰テストで解消する。仕様書の追加だけで修正完了としない。
