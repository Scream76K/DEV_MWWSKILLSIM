# r106: 不屈の比較条件選択

既定値はr105と同じ最大側2回。比較共通条件で0／1／2回を選べる。通常側は常に未発動基準、最大側だけ選択回数の資料倍率1／1.1／1.21を適用する。未発動0回では不屈の追加倍率がないため、不屈固有の加算順序保留は不要。他の未対応条件を解除しない。

実際の回数をゲームから取得する機能ではない。グループ3部位判定とDPS保留はr105のまま。1／2回は攻撃加算との順序未確定を理由に最大側を保留する。

UIの回数変更で比較キャッシュ・JSON出力を無効化する。比較時の共通条件と適用レコードに選択回数を保存する。比較中のビルド切り替え・復元でUI値を変えない。未指定の関数呼び出しは2回、無効値は通常を残し最大側のみ保留。
