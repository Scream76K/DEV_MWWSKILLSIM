# r101: 大剣ダークアーツの通常火力指数

## 対応範囲

固定STANDARDの溜め斬りⅢ → 強溜め斬りⅢ → 強なぎ払いⅢについて、ダークアーツ有効時の通常火力指数に本体と衝撃波2回を含める。全Hit命中を仮定した資料ベースの未丸め参考値であり、実測命中回数や実機検証済みのダメージではない。

発動判定は従来のシリーズスキルの厳格な判定を継承する。数値はGS_DARK_ARTS_WAVEの登録値を使用し、個別技のsourceHitRules.darkArtsWaveから対象イベントを数える。未登録の対象技への拡張は推定しない。

本体の武器属性とは独立した龍属性追撃を扱う。龍肉質は⑥の専用欄で明示入力する。武器の属性肉質を流用しない。龍属性攻撃強化、通常会心率、超会心、物理・属性斬れ味を使用する。龍肉質未入力・0等は計算保留とする。対象モンスター・部位・鎖刃状態の変更時に専用欄を消去する。共通条件の記録と比較出力に入力値を含める。

## 保留する範囲

- 最大火力指数：赤ゲージ時の追撃属性強化・併用条件の接続は未実装。
- 暗黒、チャージマスター、会心撃【属性】併用：技中の作用を無視せず通常側も保留。
- 絶対1Hitダメージ・コンボDPS：従来の特殊効果ゲートを維持。
- 全大剣技への追撃対象拡張：今回の3技の固定STANDARD以外は推定しない。
