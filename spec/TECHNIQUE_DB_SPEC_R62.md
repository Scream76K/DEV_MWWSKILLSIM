# r62 狩猟笛の音波・固定ダメージ参考計算UI

## 今回の変更

技DB確認欄の付近に折り畳み式の参考計算欄を追加。r61の参考計算APIを画面から呼び出せる。通常の装備・コンボ・ビルド比較の出力には接続しない。

## 操作

1. 「狩猟笛の音波・固定ダメージ参考計算」を開く。
2. 武器係数を使わない計算用攻撃力、表示属性値、属性肉質を入力。無属性は属性値0。
3. 演奏衝撃波、通常攻撃時の響玉追撃、旋律成立時の響玉追撃、重ね掛け固定10の各回数を入力。発生しないものは0。
4. 「参考値を計算」を押す。

全欄は初期値なし。空欄を0と解釈しない。既存の追撃4回の観測から種類や内訳を推測しない。回数は0以上の整数、他の値は0以上の有限値。不正入力や計算拒否は結果を表示せず、理由を案内する。

結果は音波の物理・属性・固定・参考合計に分ける。本体攻撃を含まないこと、全体DPS・ビルド比較に使えないことを同じ結果欄に表示する。未丸めはゲーム表示の丸めを適用しない意味であり、画面上の数値は表示精度を12桁に整える。

入力変更で前の結果を消し、再計算を促す。入力内容は永続保存せず、装備・OCR・通常比較の状態に書き込まない。結果はtextContentで描画し、ユーザー入力をHTMLとして埋め込まない。
