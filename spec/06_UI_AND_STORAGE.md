# UI・保存・読込・比較
- iPhoneブラウザ／GitHub Pagesで動作すること。ゲーム風UIを維持し、横スクロールは比較表内に限定してページ全体の横はみ出しを防ぐ。
- 装備・スキル選択、コンボ作成、ビルド保存・読込・比較を提供。旧データの読み込みはマイグレーションの安全性を確認する。
- 保存済みビルドの武器種はMHDB由来の確定メタデータを使う。武器種欠落や不一致を名称推測で補わない。
- 異武器種の火力指数・会心率の直接比較は禁止。異武器種の優劣は検証済みコンボDPSが揃うまで保留。
- 比較は非正規化計算値を主表示し、基準比の%・物理／属性／特殊寄与を補助表示。JSONでも分離する。
- UIの小数表示は原則1桁。内部計算値を丸めない。
- 実測A/B診断は試験的機能。検証前に正式な数値と混同しない。
