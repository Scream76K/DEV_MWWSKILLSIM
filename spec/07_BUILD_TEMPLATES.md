# ビルドテンプレートDB
- 対象は14武器種×5カテゴリを構想するが、70件の数合わせより実用性・根拠・検証を優先。
- source_confirmed（資料から読み取れた）とverified（MHDB／ゲーム内条件と整合）を分離する。未検証項目は推測補完しない。
- エキスパート資料: こたつ氏の各武器「簡単厳選ver」、さらだ氏の弓5パターン。URL・採用箇所・検証状態を保持する。
- 護石・装飾品・武器ボーナス・シリーズ条件をMHDBと照合。名称の似た珠や複合珠、攻撃／巧撃の混同に注意。
- 重複ビルドと役割重複を整理。テンプレ適用後は武器、護石、スキル、スロット、ボーナスが実際のUIへ反映されたことを確認する。
- さらだ氏の龍属性弓テンプレは流水・積弾を破龍・積弾へ変更するというユーザー指定を保持する。ただし実在性はMHDB照合を要する。
根拠: ユーザー指定のテンプレ方針、既存テンプレ研究。テンプレ全件の現行データ照合完了を意味しない。
