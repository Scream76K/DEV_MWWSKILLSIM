# r59 Hit単位の攻撃力補正

## 目的と範囲

既存genericProfileDamageに、対象Hitだけへ攻撃力補正を適用する入力を追加。将来、資料確認と採用判断が済んだ飛燕などを最終ダメージ全体へ一律に掛けずに扱うための計算基盤。現在の実データへの飛燕適用は行わない。

## 入力契約

通常Hitに任意のphysicalAttackModifierを指定できる。指定する場合は以下を全て必須とする。

- multiplier：有限の数値、0以上。文字列は不可。
- adoptionStatus：ADOPTED。
- evidenceRef：空白でない参照ID。

指定なしは従来どおり。明示的なnull、未採用、不正値や根拠不足は計算拒否。adoptionStatusは呼び出し側の明示的な採用宣言であり、この関数が資料を検証したことを意味しない。実データの採用判断は技DBの責務。

選択されたdamageStatsStateのbaseAttackに補正を掛け、MV・斬れ味・肉質・会心を含む通常物理計算を行う。属性計算、部位耐久、猟虫などの特殊成分には流用しない。入力済み攻撃力に同じ補正を重複計上しないことは採用側の責務。

traceには適用した補正と根拠を別オブジェクトとして保持。入力を変更しない。sourceHitRulesは計算に使用しない。

## 検証

node --test tests/*.test.cjs：82件成功。

新規テストは対象Hitのみの物理補正、属性据え置き、状態別攻撃力とMAX会心、無効入力の拒否、traceと入力の分離、操虫棍の計算保留を確認。例：攻撃力200・MV100・物理肉質50の2Hitで最初だけ1.1倍なら物理210。属性値100・補正1・属性肉質20なら属性合計4のまま。

既存のMV/属性配列、資料レコード、OCR、装備UI、STANDARDの実データ出力は変更しない。ゲーム内の丸めや飛燕の詳細適用順が確定したという扱いはしない。
