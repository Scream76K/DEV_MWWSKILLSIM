# 技・コンボ・DPS
- UI操作は「武器 → 技 → コンボ → DPS」。同じ技を複数回使う場合は技を複数回追加し、回数の数値入力に置き換えない。
- 大剣STANDARD: 溜め斬りⅢ → 強溜め斬りⅢ → 強薙ぎ払いⅢ。
- 片手剣STANDARD: 技入力列 18 → 17 → 27 → 28（名称はTechnique DBと照合）。
- 双剣乱舞Ⅰ・Ⅱ・ⅢはHitの区間を区別し、全27Hit構造は資料と実機で検証を継続する。
- コンボ総ダメージと所要時間を別に扱い、DPS = 総ダメージ / 所要時間。所要時間が不明・未検証の場合はDPSを表示せず理由を表示する。
- コンボDPSはコンボ全体の実計算値であり、1Hit期待値やSTANDARDの火力指数で代替しない。
- 同条件の動画で各Hit、開始／終了時刻、会心・バフ・肉質・距離・状態を確認する。
根拠: ユーザー確定事項、r139実装、検証計画。
