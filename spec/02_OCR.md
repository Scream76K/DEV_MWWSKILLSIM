# OCR・画像切り出し
- 現行方式: 装備一覧の水平線を基準としたトップダウン9行グリッド。旧アイコンアンカー方式は現行の基準ではない。
- 行順: メイン武器、サブ武器、頭、胴、腕、腰、脚、護石、装衣。
- 座標変換: 物理画像 → ゲームビューポート → 0〜1正規化 → 物理Crop座標。4Kと画面表示座標を混同しない。
- フルスクリーン、上下黒帯、枠撮影に対応する設計。画像別の精度を継続検証。
- 文字列の左右端が切れていないことをOCR精度評価より先に確認する。OCR結果はMHDBに照合し、曖昧な名称を勝手に確定しない。
- 読み取り画像の該当部分を候補と並べる。根拠のある第一候補は選択済みにし、切り出しが成立しない行には候補を表示しない。
- 同じ防具名のα・β・γが同点なら、候補は残すが自動選択しない。型が決まるまでは装飾品の装着上限を不明として扱い、型を選んだ時点で再判定する。不明は「枠なし」と区別する。
- ビルドへ反映するとき、護石だけが未確定なら、確定したほかの装備・装飾品を反映する。現在の護石・スキル・装飾品は変更せず、未反映の旨を表示する。ほかの装備・装飾品と、適用対象の護石の確認条件は省略しない。
- 実画像による検証では、切り出し・認識・MHDB照合・候補確認・反映を分けて確認する。OCRの確認には装備・装飾品・護石データと、キャッシュの検証に必要なHTTPSまたは端末内のlocalhostを用いる。実際の検証画像は配布物に含めない。
- 武器14種のアイコン対応。ガンランス欠落などの再発を防ぐ。
根拠: 2026-09-24確定のグリッド方式、OCR修正履歴。
