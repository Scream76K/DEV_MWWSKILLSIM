# OCR・画像切り出し
- 現行方式: 装備一覧の水平線を基準としたトップダウン9行グリッド。旧アイコンアンカー方式は現行の基準ではない。
- 行順: メイン武器、サブ武器、頭、胴、腕、腰、脚、護石、装衣。
- 座標変換: 物理画像 → ゲームビューポート → 0〜1正規化 → 物理Crop座標。4Kと画面表示座標を混同しない。
- フルスクリーン、上下黒帯、枠撮影に対応する設計。画像別の精度を継続検証。
- 文字列の左右端が切れていないことをOCR精度評価より先に確認する。OCR結果はMHDBに照合し、曖昧な名称を勝手に確定しない。
- 武器14種のアイコン対応。ガンランス欠落などの再発を防ぐ。
根拠: 2026-09-24確定のグリッド方式、OCR修正履歴。
