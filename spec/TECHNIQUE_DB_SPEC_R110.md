# r110: 基準ダメージと火力変化率

ユーザーの2026-10-08指摘に基づき、基準100表示を画面から除去。基準ビルドの通常STANDARDコンボ全体の期待ダメージ（ゲーム表示丸め前）を基準ダメージとして表示する。1ヒット期待値とは別の値。

基準ビルドの通常セルは実ダメージ「（基準）」。比較ビルドの通常、全ビルドの最大は同じ基準通常ダメージBからの変化率 `(D/B−1)×100`。最大の分母も基準の通常であり、最大同士を比較しない。基準の選択変更時は全セルとJSONを再計算。

括弧内に物理／属性の増減寄与率をまとめる。各寄与率は `(候補成分−基準通常成分)/B×100`。各成分自身の変化率やダメージ構成比とは区別する。例：基準物理800＋属性200、候補物理880＋属性180なら `+6.00%（物+8.00%／属−2.00%）`。特殊成分があれば別記。丸め前の全寄与の合計が全体の変化率になる。基準属性0からの増加も基準全体を分母とするため計算可能。

未対応武器、異なる武器種／STANDARD、基準未算出・0以下、最大保留は推定しない。太字判定は全比較ビルドの値に対して行う。

比較JSONをschemaVersion 2へ更新。baseline.damage/componentsとresults.powerChangeに実ダメージ、全体変化率、成分ダメージ、増減寄与率を保存。componentChangePercentは各成分自身に対する変化率を併記（基準0から増加時null）。旧powerIndex/maxPowerIndexは後方互換用の基準100値として残し、注記で区別する。DPS指数・計算式は変更しない。

r109の固定列幅112/120px、最大474px、最大3ビルド同一表、局所横スクロールを継承。ダメージ計算・スキル条件・保存／読込は変更しない。
