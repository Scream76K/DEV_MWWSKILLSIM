# r66 比較表の固定列幅と折り返し

r65では1件と3件で項目列の幅が違うとの実機報告があった。Chromiumでは再現していないため、Safari固有の原因とは断定していない。

項目列112px、ビルド列120pxをcolgroupの直接px指定で固定。表も1件232px、2件352px、3件472pxの直接px指定を使い、最大472pxとする。枠線込みの結果領域上限は474px。

compareOutの内側の利用可能幅と上限から、1つの表に収まるビルド数を求める。収まらない分は下へ別表として表示し、各表に項目列を繰り返す。長い名前とセル内容は折り返す。表示領域が1ビルド分より狭い場合のみ局所横スクロールで内容を保つ。

最大値の太字は分割前の全ビルドを基準とする。リサイズ時は保存した比較結果を再描画し、火力を再計算しない。比較の1〜3件制限、装備保存、OCR、計算式、技データは変更しない。

既存92件、DOM統合3件、Chromium4件、計99件成功。320/390/430/768/1280pxで保存3件→比較の実ボタン操作を確認し、ページ幅の増大なし。1/2/3件で112/120pxの列実測、長い名前の保持、全件の保持、最大表幅、分割後の全体最大値強調を確認。390→1280→390pxのリサイズで3表→1表→3表と再描画し、数値と最大値を維持。

ブラウザの保存操作は明示的な空データで検証しており、実ゲームの火力検証ではない。iPhone Safari実機の再確認は未実施。

再現：npm ci後、npm test、npm run test:dom、ブラウザ準備後npm run test:browser。ブラウザ本体・node_modulesはZIPに含めない。
