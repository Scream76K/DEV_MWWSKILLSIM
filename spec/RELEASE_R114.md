# r114 — Bow Critical Element

回帰確認：単体127件、DOM262件、既存ブラウザ40件すべて成功（失敗0）。追加ブラウザ1件も成功、合計430件。追加を含む弓スキルのブラウザ2件もまとめて再実行し成功。

弓の固定STANDARD（溜め3・射撃→剛射→剛連射、14矢全命中）に会心撃【属性】Lv1〜3を接続。

- 資料係数：1.05 / 1.10 / 1.15。属性期待値は `1 + max(0, 会心率)/100 × (倍率−1)`。
- 通常・最大はそれぞれの会心率を使用。負の会心で属性ダメージを減らさない。
- チャージマスターは属性の基礎倍率へ、会心撃は加算込み属性ダメージへ各一回適用。
- 物理成分、斬れ味除外、ビン補正の属性非適用、基準ダメージと寄与率表示、表示一桁の丸めは維持。
- 状態異常属性はHP属性ダメージへ変換しない。不正なスキル段階は計算保留。
- 出典： https://kuroyonhon.com/mhwilds/d/dame.php の会心撃【属性】選択肢（取得2026-10-08）。弓は「他」の倍率。資料参考値であり実機検証済みではない。
- 貫通、ファーストショット、フォースショット、刃鱗増装、未確認の条件付き属性倍率とチャージマスターの順序は引き続き保留。

追加の5項目は実装前に失敗を確認し、実装後に成功。実際の保存ビルドから会心撃【属性】Lv3を読み込み、属性寄与率を小数1桁で比較表へ表示するブラウザテストも成功。
