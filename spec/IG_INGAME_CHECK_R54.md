# 操虫棍：今晩の実機確認

まずは以下の短い動画があれば調査を進められます。今ある本体6Hitの確認記録は保持しています。全技の調査は不要です。

## 1. 装備と条件

動画の最初に、ゲームバージョン・武器・攻撃力・属性値・会心率・発動スキル・猟虫種類を見せてください。トレーニングルームで同じ標的・位置・斬れ味を使います。食事や一時的な攻撃力上昇がある場合も記録してください。

## 2. 地上と空中を分けた派生

| 動画 | 操作と状態 | 確認する点 |
|---|---|---|
| A | 三色→地上で溜め1の強化急襲斬り→飛天螺旋斬 | 地上のHit順、溜め補正、エキス消費時点 |
| B | 同じ条件で地上の溜め2→飛天螺旋斬 | Aとの物理差、飛天中のエキス回収タイミング |
| C | 三色→跳躍→空中で溜め2の強化急襲突き | 地上との区別、3Hit目の属性判別用の基準 |

手動の溜め操作で段階を揃えます。舞踏跳躍の成功回数や△＋○からの派生が混ざる場合は教えてください。飛天では本体と猟虫が両方攻撃するため、画面に出た数字の総数をそのまま本体Hit数に数えません。

既存STANDARDの急襲技が地上か空中かも、この動画と意図するコンボで確定します。地上で繋ぐ技は「斬り」、空中から降下する技は「突き」です。

## 3. 属性0／1の判別（余裕があれば）

空中の強化急襲突きの3Hit目が、資料によって属性0と1に分かれています。同じ武器の属性強化スキルだけを変更し、Cをもう一度撮ってください。物理攻撃力・会心率・斬れ味・標的・溜め・舞踏跳躍・エキス状態は揃え、属性値の変更前後を記録します。

属性肉質が0の標的では判別できません。属性差が小さい場合は丸めで数字が同じになることもあるため、変化なしだけで属性0とは断定しません。動画とステータスから計算を照合します。

## 優先順位

A・B・Cと装備情報が最優先です。属性変更の追加撮影やDPS用の時間測定は、その結果を見て必要な範囲に絞ります。
