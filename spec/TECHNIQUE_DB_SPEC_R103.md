# r103: 大剣・暗黒の事前発動最大火力指数

## 対応範囲

ダークアーツを伴わない大剣の固定STANDARDに、武器スキル「暗黒」Lv1の事前発動を仮定した最大側の攻撃力補正を接続する。通常側は他の条件付き効果と同様に暗黒未発動の基準値を維持する。この通常側は、コンボを実行しても暗黒が発動しないという意味ではない。

資料：https://kuroyonhon.com/mhwilds/program/skill.php （暗黒）。2026-10-07確認。資料記載の攻撃力1.1倍、30秒、体力消費20をSTANDARD_DARK_SOURCEに保持。計算は整合したattackComponentsがある場合に、武器基礎攻撃力の乗算段階へ倍率を適用し、通常・条件付きの固定加算をその後に適用する。属性成分へ攻撃倍率をかけない。

最大側は強化が全Hitで有効な事前発動状態の参考値。効果時間と体力消費は条件説明用の情報であり、コンボ内の時間・体力のシミュレーションには使用しない。暗黒未装備の計算は変更しない。攻めの守勢併用時も個別倍率を保持し、暗黒倍率を上書きしない。

## 保留条件

- 大剣以外、未確認の段階、攻撃力内訳の欠損・不整合：最大側を保留。
- フルチャージ併用：体力消費後の回復・満タン状態の併用計算が未接続のため最大側を保留。30秒間ずっと排他的と断定しない。
- 暗黒とダークアーツの併用：技中の体力状態・追撃の作用を解決していないためr101の保留を維持。
- コンボ内の発動・非延長のタイマー・体力消費、絶対1Hitダメージ、コンボDPSへの暗黒補正の接続：今回の対象外。

## UI・保存

比較結果に通常側の未発動基準、最大側の事前発動、効果時間と体力消費、実機・技中タイミング未照合を表示する。フルチャージ併用と内訳不足の保留理由を日本語で案内する。保存ビルドから読み込んだ武器スキル名・段階で判定し、推測した武器分類や新しいスキルIDを製品へ追加しない。比較出力に適用条件・資料URL・計算内訳を残す。
