# r117 — 弓のフォースショット射撃順

弓の固定STANDARD（溜め3射撃→剛射3→剛連射3）の各射撃にフォースショットを接続しました。比較条件で「装填後の開始位置」を指定します。1〜8発目から連続する3射撃を対象とし、装填内の10発目までに収まる範囲に限定します。未入力時は装備にフォースショットがありビンを使用する場合だけ保留です。

Lv1 / Lv2 / Lv3の攻撃力加算は3 / 6 / 10で、4発目と6発目だけ適用します。会心率加算は8 / 10 / 12ポイントで、4発目以降に適用します。矢のHitごとにビンを消費せず、射撃・剛射・剛連射の各アクション単位で射撃順を進めます。会心率を100%までに制限し、各射撃の会心率を物理と会心撃【属性】へ使用します。負会心で属性ダメージを減らしません。

ビンなしには適用しません。刃鱗増装の最大側は従来どおり発動直後の追加の強化3回分を仮定し、その追加ビンにはフォースショットの攻撃・会心加算を適用しません。通常側の通常ビンは指定した開始位置を使います。途中の再装填、貫通、状態異常ビン、長期の平均発動率、DPSは今回の範囲に含みません。

技DBの弓状態レコードをrevision 6へ更新し、revision 5を履歴に保存しました。数値は技DBを参照し、計算結果にはforceShot.stagesと各Hitの射撃順・加算・会心率を記録します。開始位置の変更は古い比較結果を無効化します。以前の記録に開始位置がない場合は未入力へ戻し、勝手に1発目からと解釈しません。
