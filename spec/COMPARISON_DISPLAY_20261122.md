# 保存ビルド比較・表示仕様

更新: 2026-11-22 / SPEC-20261122-COMPARE
対象: 保存ビルドの通常／最大の比較結果。比較画面の表示を更新する。計算式、保存済みデータ、JSON出力形式の変更ではない。

## 比較表

- 通常火力（基準火力）・最大火力は実計算値を表示する。通常は実数のみ、最大には**同じビルドの通常からの増減率**を併記する。他のビルドを選んでも増減率の基準は変わらず、画面には基準100の正規化指数を表示しない。
- 物理・属性の内訳も同様。最大の割合は各成分の通常値を分母とし、全体の割合は通常合計を分母とする。増減率 = `(最大 − 通常) / 通常 × 100`。丸め前の値で計算し、表示は小数1桁。分母が0・未算出なら最大の実値は残して割合を「—」とする。最大値自体が未算出なら推測で埋めない。
- 武器固有成分は、ビンなど合計に既に含まれる内訳。値が確認できる非ゼロの成分を含む比較でのみ行を表示する。不明な成分は0に置き換えない。「ビルド間比較の出力用基準」および従来の出力用相対値は、画面の最大増減率とは別であり、既存の互換性を維持する。
- 最終行に「固定ダメージ」を表示する。通常・最大で同じ発動1回あたりの参考値は1回だけ、異なる場合は通常／最大を分ける。関連する参照がなければ「—」、値が未確定なら「未算出」。主表の合計・内訳・増減率には加えず、発動回数も推定しない。例：灼熱化Ⅰの表示は固定分20.0のみ（火属性分とは別）。鎖刃刺撃のLvと下位／上位は[第4弾アップデート後の採録値](https://gamewith.jp/mhwilds/486373)（[再照合資料](https://kuroyonhon.com/mhwilds/program/skill.php)）に従う。Lv2は120.0／160.0、Lv3は160.0／220.0。比較対象ゲーム版での再実測済みとは扱わない。

## コンボと書体

- 「計算に使用したコンボ」は、注記類の後、最初の火力表の直上に表示する。実際に使った技名・回数を示し、同じ場合も「通常：」「最大：」で分ける（例：ライト速射＋刃鱗増装［最大］＝強化速射3回 → 通常の速射2回）。算出不能と、算出済みだがコンボ未確認は区別する。チャージアックスの独立R/Hを連続技として表示しない。
- 承認済みB書体のM PLUS Rounded 1cを本文・見出し・フォーム・表に使用し、同梱のRegular/Boldを配信する。小さい実機でも読みやすい濃紺のコンボ欄とし、候補はコンボ見出し17px、本文14〜16px、ビルド名などの小ラベル13〜14px（基準16px時）。ブラウザ標準の拡大を妨げない。

## 比較の入口と詳細設定

- ⑦の冒頭の短い案内に続けて「ビルド選択」を表示し、単独の「設定」見出しや選択したビルド名の重複行は表示しない。画面読み上げ用の選択状態は維持する。
- 通常・最大の合計値だけを少し大きく太く表示する。詳細設定の不屈の選択欄は最大火力のスキルと同じ枠に置き、狭い画面では枠内で折り返す。既存の選択肢・計算条件は変えない。

- 初期状態は両方とも閉じ、対象はトレーニングルーム／正面。対象と関係のない任意条件は「詳細設定」に置く。
- 挑戦者・弱点特効・狂竜症は、比較に選ばれた装備で成立する項目だけを「最大火力に反映するスキル」に表示する。既定はチェックあり。外した補正のみ最大火力から除き、通常火力、他の補正、武器・ビルドデータは変えない。チェックは発動条件（部位、傷など）を上書きしない。
- 根性【果敢】は消費前で固定し、選択肢を表示しない。⑦の大剣ダークアーツは画面で選んだ対象を本体と衝撃波に使い、龍肉質をその部位から読み込む。通常設定には手入力欄を出さない。龍肉質が数値0なら本体を残し、最低ダメージ処理が未検証の衝撃波だけ未算出。部位データ欠損・不正値と未採用の状態別肉質は既存の検証を維持し、数値を補わない。保存済みの旧入力は書き換えない。

- 火力結果の但し書き（未反映効果、属性・耐性変換、暫定条件、適用条件、算出保留理由など）は、保存比較と指定コンボのどちらも閉じた「火力計算の注釈」1か所にまとめる。反映した条件と未反映の効果をビルドの見出しに集約し、全対象で共通なら「全ビルド共通」に1回だけ記載する。対象側が異なる場合は通常／最大を区別する。同じスキルの計算対象外と未算出の追加ダメージは1行にまとめる。⑤スキル構成では「選択技の実計算」ブロックを表示しない。スキルIDと内部診断コードは結果画面に出さない。固定ダメージ欄、火力値、計算・診断データは変更しない。
- 選択欄と候補メニューは濃いネイビーに白文字。対応ブラウザーはネイティブ選択欄のメニュー自体にも配色を適用する。
- 歴戦王アルシュベルドの新規選択は1件。脚の左右をまとめ、右翼・左翼の選択肢は設けず、鎖刃は解放／解除別とする。旧データ取込の別名は保存復元のために保持するが候補には出さない。未採用個体には明示して、通常個体の肉質で代用しない。
- 通常・歴戦アルシュベルドおよび護竜アルシュベルドも同じ部位名を用い、それぞれ自身の部位IDと肉質を使用する。解放鎖刃の肉質が採用されていない場合は選択不可とし、解除時の値を流用しない。オメガ・プラネテスの同名候補は、零式固有の別肉質表がないか同じ値の場合は1件だけ表示する。
- ウズ・トゥナの部位は本体とヴェール（水膜）に分け、部位名を日本語にする。アジャラカンとゴグマジオスの位置を特定できない hide 部位は新規選択に表示せず、旧保存のIDは保持。
- シーウーは通常・歴戦とも傘膜・触腕・口・第1〜第3腕を明示する。ジン・ダハドは凍成殻（腰部）と大凍成殻（露出前／後）を区別する。
- ゴア・マガラの通常・歴戦では「翼」と「翼脚」を別部位とし、左右名を日本語表示する。
- ゾ・シアの頭と左右翼腕は白纏晶と本体を区別。本体2行は斬撃肉質を表示し、元データにない状態名は付けない。タマミツネは爪・背ビレ、チャタカブラは尻・舌を表示。ドシャグマの尻尾は内部IDを表示しない。
- ヌ・エグドラは傘膜・触腕・口・左右第1〜3腕、ネルスキュラは外套膜・毒トゲ・腹部、ラギアクルスは前脚・後脚、ラバラ・バリナは花弁状部を表示する。ヌ・エグドラ、ネルスキュラ、ラギアクルス、レ・ダウの部位名が確認できない行は、新規の部位選択に出さない。旧保存を復元するIDと採用済み肉質は変更しない。
- 「技構成」は「コンボを自分で組む」内に置き、現行プリセットを技名だけで選べる。開始条件とは分け、旧参考プリセットは表示しない。既存の技ID・保存データ・計算経路は維持する。
- 火力表の行見出しは「通常火力」「最大火力（通常火力比）」。最大火力の数値は実計算ダメージ、括弧内は同じビルドの通常火力との差率とする。
- 全ビルドで通常・最大それぞれの実行済みコンボが一致する場合は「全ビルド共通」として1組だけ表示し、通常・最大のラベルは維持する。いずれかが異なるか確認できない場合は個別に表示する。

## スキル構成比較

- ビルドごとのスキル数や詳細の開閉にかかわらず、「シリーズスキル」「グループスキル」の開始位置を全列で揃える。
- ⑦の火力表の直下に、比較した保存ビルドのスキル構成を同順・最大3列で表示する。⑤と同じ通常・シリーズ・グループのカード、現在Lv・全Lvの開閉を使用する。
- 保存装備を現行DBで復元して表示する。編集中の装備や火力の発動条件とは混ぜない。旧保存で必要項目が欠ける場合は、その列が確認できないと表示し、他の列は維持する。保存・計算・出力形式は変更しない。
- スマートフォン縦画面（320 CSS px 以上）でも最大3列を横スクロールなしで表示する。狭い画面では列の余白とレベルの目盛りを詰め、スキル名は折り返す。さらに狭い表示環境では列を縦積みにせず、この欄内だけ横スクロールできる。

## ベータで非表示にする補助機能

- 「シリーズスキルから装備を提案」と「AI装備相談」は画面から外す。装備登録、シリーズスキルの集計、保存、火力比較は引き続き利用できる。コンボ設計および比較への新しい接続は本候補に含めない。

## 護石UI

- 護石出現ルールへのショートカットと「護石生成可能性」の説明を画面から外す。護石ルールによる内部の候補絞り込みは維持する。
