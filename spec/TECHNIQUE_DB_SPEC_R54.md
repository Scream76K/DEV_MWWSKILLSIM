# r54 — 操虫棍の地上・空中・溜め段階の整理

## 今回の変更

既存DBの強化急襲斬り（地上）を溜め0・1・2で整理しました。空中の強化急襲突きは、溜め1・2と舞踏跳躍0・1・2回の6候補を別IDで追加しました。空中の溜め0は資料の個別行で確認できないため追加していません。登録は計531件です。

地上技と飛天螺旋斬の溜め別MVには物理補正を一度だけ反映しました。反映前の登録はrevisionHistoryに保存しています。属性補正は物理補正で縮小していません。新しい計算を許可した変更ではありません。

空中技はKUROYONの溜め・舞踏跳躍別MVを登録しています。3Hit目の属性補正はKUROYONで0、まかろんで1です。KUROYONの各溜め行で明示されていない他Hitの属性を1と仮定せず、候補データの欠落として残しました。まかろんの全Hit属性1は溜め段階未記載の別候補に保持しています。

飛天螺旋斬は既存の本体6Hit候補を保持し、溜め1は本体48×6、溜め2は64×6、属性は各0.8で登録しています。KUROYONも両段階で本体6Hit・猟虫6Hitです。まかろんの表は本体5Hit・猟虫5Hitなので、資料差は未解決として表示します。ガムの合計MV384は6Hit候補との照合根拠です。5Hit候補に溜め段階を推定して付与していません。

## 状態・成分・計算への扱い

- 資料上、飛天螺旋斬は発動時に三色エキスを消費し、エキスなしのステータスで攻撃します。発動条件と攻撃時の状態を別メタデータにしました。
- 攻撃中のエキス回収は位置・猟虫などで変動するため、成功や三色再取得を仮定しません。
- 猟虫の資料値16は通常の武器倍率依存MVとして本体に混ぜません。猟虫のHit数・専用計算・属性の扱いは別確認です。
- 未記載の部位補正は補完しません。r53のHP／部位耐久分離方針を継続しています。
- 旧STANDARDの急襲技IDには地上と空中の候補を関連付け、技名対応の保留を明記しました。旧合算値を新しい技のMVとして使いません。
- 操虫棍STANDARDはEVIDENCE_GATEDのままです。採用技・溜め段階、属性資料差、エキス状態の計算対応、バージョン監査が必要です。技プルダウンやDPS計算へ候補を昇格していません。
- 全技DB COMPLETEではありません。双剣のr53通常ダメージ比較と大剣修正は維持します。
