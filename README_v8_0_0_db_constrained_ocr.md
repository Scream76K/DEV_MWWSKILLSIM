# v8.0.0 DB制約型OCR

今回のOCRは「正解はMonster Hunter WildsのシミュレータDB内に存在する」ことを前提に、Tesseractの生文字列をそのまま正解扱いしない方式へ変更。

- 画面アンカーを正規化して検出
- 部位ごとに該当カテゴリのDBだけを候補にする
- 編集距離＋LCS＋2-gram類似度を合成
- α/β/γなどの末尾情報を加点
- UI/status行を減点・除外
- アンカーからのY位置をスコアに反映
- 同一スクショ内で部位ごとに独立評価
- 装飾品は「珠」を含む行のみ装飾品DBと照合
- 低信頼候補は確認UIに出さず「該当なし」として扱える
- 既存の護石「防2-防1」選択修正を継承

## 目的

「OCRが完全に文字を読めること」ではなく、「多少崩れた文字から、ゲーム内DBの正しい項目を推定すること」を優先する。
