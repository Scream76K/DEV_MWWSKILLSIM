# MH Wilds OCR — Step 1.25-B v3.1.3

## 今回の変更
- 装備9行の構造検出後、各行の既知のアイコン位置を利用してアイコン枠を局所探索。
- 画面全体のランダムな色・文字候補をアイコン候補として拾う方式ではなく、対象行の左側だけを探索。
- アイコンの「暗い内部＋明るい枠＋色付き画素」という構造をスコア化。
- アイコン検出結果を可視化し、その右側から装備名OCR領域を自動生成。
- アイコン起点領域を生成すると、以後の装備名OCRはその領域を優先使用。従来の名前アンカー方式はフォールバックとして残す。
- RARE判定は今回の主処理から切り離し、実装していない。

## テスト手順
1. スクリーンショットを読み込む
2. 「画面構造を自動検出」
3. 「🎯 アイコン起点OCR領域を生成」
4. 各対象で「アイコン起点」と「右側OCR領域」が実際の位置に合っているか確認
5. 問題なければ「装備名を一括認識」

## 設計意図
今回の段階ではRARE度を確定値として扱わない。将来、候補の参考情報・加点要素として利用できるよう、アイコン起点の構造を優先する。
