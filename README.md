# MH Wilds OCR — Step 1.25-B v3.1.2 Name Crop

Monster Hunter Wilds の装備変更画面を対象に、OCR前処理を改善する前に「装備名がOCR画像内へ正しく収まっているか」を解決する開発版です。

## v3.1.2 変更点

- 装備名クロップを固定 `rw × 0.62` から脱却。
- 画面全体の一次OCRで得られた「装備名らしい行」のBounding Boxを、文字内容とは独立した幾何情報として保存。
- 実際の装備名BBoxを基準に、左0.3×文字高、右1.0×文字高、上下0.18×文字高の動的余白を付与。
- 右端は装備カード境界を越えないように制限。
- 一次OCRで装備名BBoxが得られない場合は、意味領域のカード幅を使うフォールバックへ移行。
- メイン武器・5防具・護石を対象。サブ武器・装衣は構造検出のみで反映対象外。
- この段階では前処理方式や本体OCRの判定ロジックは変更せず、切り出し境界を先に固定する。
- 既存の4方式クロップ比較UIは視覚的な回帰確認用として維持。

## 検証ゴール

1. 長い装備名の先頭文字が切れない。
2. `α / β / γ` を含む末尾が切れない。
3. 左側の装備アイコンを極力巻き込まない。
4. 右側のスロットアイコン領域まで無制限に広げない。
5. 解像度・表示倍率が変わっても固定ピクセル幅に依存しない。
6. OCR処理を追加せず、切り出しだけを検証できる。
