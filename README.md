# DEV_MWWSKILLSIM OCR Step 1.5 — 信頼度融合

Step 1.4の高速4回OCRを維持し、TesseractのOCR信頼度を正式な判定材料として追加。

## 方針
- OCR信頼度は「正解率そのもの」ではなく、そのOCR結果をどれだけ信用するかの重みとして使用。
- 高信頼OCR（目安80%以上）＋高い辞書一致率なら早期終了。
- 高信頼OCRだけで決められない場合は、複数OCRの支持を統合。
- 辞書一致が弱い場合、OCR信頼度だけでは自動確定しない。
- 候補間marginを使って僅差の誤判定を抑制。
- 短い名前や曖昧な候補への動的閾値は、実DB検証後に追加する。
- 下段のサブ武器は対象外。

## 目標
Geminiテストの「一致率90%＋OCR信頼度88%」のような強い結果を積極的に利用しつつ、単一OCRの誤認識を複数証拠で防ぐ。
