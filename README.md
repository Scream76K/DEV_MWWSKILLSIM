# MHWilds OCR v4.5.6

## v4.5.6変更点

- 装備名OCRの処理は変更していません。
- 装飾品グループ構造も変更していません。
- 防具・護石DBのキャッシュキーを V1 → V2 に更新し、過去キャッシュの古いスロット配列を再利用しないようにしました。
- 装備DB読込時に `slotLevels` / `decorationSlots` / `slots` を共通のスロット配列へ正規化します。
- `[2,1]` のような複数スロットを1個に欠落させないよう、配列・ネスト・数値キー形式を検証対象にしています。
- 内部検証基準：
  - メイン武器 [3,3,3]
  - サブ武器 [3,3,1]
  - 頭防具 [3,1]
  - 胴防具 [3,2]
  - 腕防具 [2,1]
  - 腰防具 [2,1]
  - 脚防具 [3,3]
  - 護石 [1,1,1]
  - 合計19スロット
- 「攻撃珠II→III」のような別枝への自動置換は行いません。OCR文字列とDB枝番号が一致する場合だけ候補にします。
