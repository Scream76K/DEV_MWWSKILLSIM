# MH Wilds OCR — Step 1.25-B v2.8

装備名OCRの原点回帰版。今回の目的はDB候補統合を複雑化することではなく、**OCRへ渡す装備名画像そのものの品質を上げること**です。

## v2.8 変更点

- 装備名OCRの開始位置を、可能なら意味ラベルから得た `labelX` に固定。
- `labelX` がない場合も、カード左端から少しだけ内側へ入り、装備アイコンの混入を抑制。
- `labelWidth`（「頭防具」などのカテゴリ文字幅）を装備名幅の上限として使わない。
- 装備名は長い日本語名を最後まで保持できる幅を確保しつつ、右側のスロットUIへ広げすぎない。
- OCRパスは3回のまま維持。
  1. 白文字強調
  2. 白文字・色除去（HSVベース）
  3. グレースケール
- 大津二値化を追加するのではなく、実画像評価で比較的有効だったHSV白文字抽出へ置換。
- 武器・防具・護石の候補統合ロジックは今回の主目的では変更しない。
- メイン武器のみを対象とし、サブ武器・装衣は反映対象外。

## 実画像を使った評価

今回の評価では、実際のMonster Hunter Wilds装備画面をこちらの環境で前処理し、OCR結果を確認してから実装しています。

特に `IMG_9324` 系の頭防具では、元画像上の `護雷顎竜ヘルムβ` が明瞭である一方、広い領域をOCRすると文字以外のUIが混入することを確認しました。そのため、v2.8では候補DB側の救済より先に「名前文字列だけをOCRへ渡す」ことを優先しています。

## 開発上の原則

今後のOCR改善では、次の順序を基本とします。

```text
実画像
 ↓
前処理
 ↓
前処理画像を目視確認
 ↓
こちらの環境でOCR確認
 ↓
REDテスト
 ↓
最小限の実装
 ↓
回帰テスト
 ↓
ユーザー環境で実OCR
```

特定の1枚だけ改善する前処理は採用せず、複数のサンプル画像で確認します。
