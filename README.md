変更したのは装備名OCRの矩形だけです。

### 装備名OCR矩形
DBアイコンを `(icon.x, icon.y, icon.w, icon.h)` とすると、

- X = `icon.x + icon.w + 8`
- Y = `icon.y + icon.h - icon.h / 2`（= `icon.y + icon.h / 2`）
- 幅 = `icon.w × 7`
- 高さ = `icon.h`

つまり、**アイコン右下角をOCR帯の垂直中心**として、アイコン1個分の高さを切り出します。

サンプルの45×45アイコンでは、

`OCR = (79, icon.y + 22.5) / 315×45`

となります。
