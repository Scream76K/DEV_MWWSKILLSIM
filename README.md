# MHWilds OCR v4.3.8

v4.3.8 は v4.3.7 のフルアイコン枠検出を維持しつつ、アイコンの最小・最大サイズをキャプチャサイズに合わせて同時に調整します。

## 主な変更
- サイズ基準を「画像高さ」から「画像の短辺」に変更。
- 基準画像 706px短辺、アイコン枠 50～82px。
- `scale = min(width,height) / 706` を基本に min/max を同時に拡大・縮小。
- 3840×2160 の場合は短辺2160pxなので scale≈3.06、アイコン枠≈153～251px。
- 左端15%のUI拘束、フルアイコン枠探索、v4.3.5の9行Gridガードを維持。
- DB一致検索は0回。DBはgeometry calibration専用。
- 9行Gridが成立しない場合は後続OCRへ進まない。

## テストで確認するログ
`scene`, `短辺`, `scale`, `アイコン枠` を確認してください。
今回の3840×2160ケースでは、`アイコン枠=153～251px` 前後になることが期待値です。
