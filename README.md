# MHWilds OCR v4.6.5

## 今回の変更
- β版/既存シミュレータで確立したDB取得ローダーを再利用する方針に修正。
- OCR画面独自の `/version` 事前疎通確認を削除。各DB APIの実取得結果を直接判定する。
- テスト用DB取得は、既存の `loadWeaponDB / loadArmorDB / loadCharmDB / loadDecorationDB` を `force=true` で順番に呼び出す。
- DB取得進行度を 0–100% と「武器/防具/護石/装飾品」の4段階で表示。
- 取得件数を各DBごとにリアルタイム表示。
- 装備OCRに必要な武器・防具・護石DBが揃った時点でStep 1 OCRを有効化。
- OCR判定ロジックは変更していない。

## テスト手順
1. 「DBを取得（テスト用）」を押す。
2. 4種類の取得件数が表示されることを確認。
3. 「4種類のDB取得が完了しました」が表示されたら装備画像を選択。
4. 「装備の画像解析を開始」を押す。

※実機からMHDB APIへ接続できる必要があります。
