# MHWilds OCR v4.6.7

V4.6.5をベースに、UI・OCR・装飾品グループ構造・判定ロジックは変更せず、ページトップのDB取得処理だけをβ版の取得方針に合わせた版です。

## DB取得
- 250件ずつlimit/offsetで全件取得
- 武器・防具・護石・装飾品を取得
- 取得済みデータはlocalStorageへ保存
- 最新取得に失敗した場合、保存済みデータがあればそれを使用
- DB取得ボタンはページトップの既存UIを維持
