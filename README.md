# DEV_MWWSKILLSIM OCR Step 1.6 — OCR↔OCR一致性融合

Step 1.5を既知の動作ベースとして、個別OCR→辞書判定を残したまま、追加の証拠としてOCR出力同士の一致性を導入。

## 追加したもの
- OCR出力同士のペア比較
- 共通文字列（3〜8文字）の抽出
- 辞書候補に含まれる共通核の支持を集計
- OCR同士の一致性を既存の辞書一致・OCR信頼度・複数支持と融合
- `・` `ー` `αβγ` 等を正規化で保持し、記号を全部削除する方式を改善
- 武器名の長さに応じて必要な候補差（margin）を動的調整
- 強いOCR結果だけでなく、複数OCRの共通部分を自動確定の根拠として利用

## 重要
既存ロジックの置き換えではなく「追加の証拠」です。
OCR→辞書、OCR↔OCR、OCR共通核→辞書の3系統を融合します。

## 制約
- メイン武器の名前OCRのみ
- 上段/メイン武器を対象とする現在のStep 1系診断版
- 固定小辞書。`window.DB.weapons` があればそちらを優先
