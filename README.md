# MH Wilds アイコン起点OCR テスト v0.1

既存OCR STEP1とは独立した実験版。

## 目的
- 画面全体OCRで装備行を見つける
- 装備行の文字BBoxをアンカーとして、左側のアイコン候補領域を生成
- アイコン候補の右側をOCR候補領域として生成
- 装備名と珠名で共通利用できる座標モデルを検証

## 今回は未実装
- アイコン形状から武器種/防具部位を自動分類
- アイコン色からRAREを判定
- 実アイコン画像とのテンプレート照合
- 本体シミュレータへの接続

色→RAREの対応情報は後から受け取って追加する。

## 使い方
index.htmlをブラウザで開き、スクリーンショットを選択して「アイコン候補を検出」。
Tesseract.jsをCDNから読み込むため、初回はインターネット接続が必要。
