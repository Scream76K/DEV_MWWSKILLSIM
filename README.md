# MH Wilds OCR — Step 1.25-C v4.0.3

## DBアイコンアンカー統合・既存v3.1.2適応型OCR接続修正版

v4.0.3は、過去に構築した **Step 1.25-B v3.1.2 のOCRエンジンを維持**したまま、前段にDBアイコンアンカー方式を統合した版です。

### 今回の修正

- DBアイコン検出で9部位の位置を確定
- アイコン右下をアンカーとしてOCR帯を生成
- アンカーから確定した領域を `sourceType: icon-anchor` として明示
- アンカー領域を「構造推定」として扱わない
- v3.1.2の装備名OCRに、アンカーで確定したOCR帯をそのまま渡す
- v3.1.2の複数前処理、DB候補統合、シリーズ・型式判定は維持
- 既存の画面構造OCRは比較・フォールバック用として残す

### 同梱DBアイコン

- `db_icons/main_weapon_sample.png`
- `db_icons/head_armor_sample.png`
- `db_icons/chest_armor_sample.png`

### テスト

付属の `step125c_v4_0_1.test.js` で、従来のStep 1.25-Bテスト群に加えて、以下を確認します。

- v4.0.3タイトル
- DBアイコンアンカー領域が9行生成されること
- アンカー領域が `inferred=false` であること
- `sourceType=icon-anchor` が設定されること
- OCR帯の座標・サイズが保持されること
- OCR切り出しが `icon-anchor-exact` を使用すること
