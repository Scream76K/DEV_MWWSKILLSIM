# MH Wilds OCR — アイコン起点テスト v0.2

OCRを使わず、スクリーンショットから装備・珠アイコンの候補を画像解析で抽出する独立テスト版です。

## 目的
- 文字位置を起点にしない
- アイコン候補を画像そのものから検出
- 候補を枠表示・拡大表示して人間が確認
- 選択アイコンの右側を次段階のOCR仮領域として表示

## 未実装
- 色→RARE
- アイコン形状→武器種/防具部位/珠
- DB照合
- Tesseract OCR

## 使い方
1. ゲーム内装備画面のスクリーンショットを読み込む
2. 「アイコン候補を検出」
3. 赤枠候補を確認
4. 候補をタップして拡大確認
5. 本当にアイコンを拾えているかを評価する
