# DEV_MWWSKILLSIM OCR Step 1.15

Step 1.13をベースに、OCR処理そのものは変更せず、武器名のDB候補評価と複数OCRの候補統合を更新。

## 今回の変更
- DB武器名を100点満点として文字数に応じて1文字の基本点を `100 / DB文字数` とする。
- 通常の文字違い：基本点の100%を減点。
- 濁点・半濁点の違い：基本点の50%を減点。
- 大文字/小文字、カナの大小（イ/ィ、ヤ/ャ等）：基本点の25%を減点。
- スペース、改行、区切り記号：採点対象外（減点0）。
- OCR側の余分な非空白文字は通常の挿入誤りとして減点。
- 各OCRでDB候補を上位3件まで保持し、OCR↔OCRの生文字列一致ではなく「同じDB武器への収束」を統合評価する。
- 最終画面では上位候補を表示し、1位と2位の差も表示。
- OCR↔OCR一致率は最終判定に使用しない。

## 検証
- index.html内のJavaScript 2ブロックを `node --check` で構文確認済み。
- OCRキャンバス/Tesseractの3パス構成は変更していない。
