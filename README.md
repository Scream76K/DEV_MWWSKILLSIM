# DEV_MWWSKILLSIM_DB_ICON_MATCH_v0_9

アンカー＋グリッド方式の検証版。
- DBアイコンは全9部位を個別に位置決めせず、最も一致度の高い1点をアンカーとして採用。
- アンカーの行番号を基準に、画面高比の行ピッチから全行のアイコン位置を算出。
- X座標とアイコンサイズはアンカーから縦一列にスナップ。
- 各アイコン右下角を基準にOCR帯を生成。OCRはまだ実行しない。
- 行ピッチは画面高比を基本値とし、px補正を用意。後段で画像から自動推定する余地を残す。
- v0.8のCanvas/ImageData修正済みテンプレートマッチングを利用。OpenCV.jsは不使用。
- サンプルDBアイコンは同じsample_game.pngから切り出した検証用画像。


## v0.9.2
- v0.9.1で残っていた ImageData とラッパーオブジェクトの取り違えを修正。`imageDataFromImage()` の戻り値を `grayData()` に渡しても正しく処理できるようにした。
- ImageData の width/height/data と内部 {w,h,g} の双方を受け付ける。
- データ長も検証し、NaN×NaN の発生箇所を早期に検出する。


## v0.9.3
- 単一ピッチ方式を廃止し、上段と防具列を別々に校正。
- メイン武器→頭防具の2区間から上段ピッチを実測。
- 胴防具以降は画面高比から防具ピッチを算出。
- 既知DBアイコンのX座標・サイズを中央値で縦方向にスナップ。
- OCRは未接続。9行の座標生成精度を検証する実験版。


## v0.10
- v0.9.3のアンカー＋グリッド座標生成を継承。
- グリッド生成後、9部位のOCR枠を順番に日本語Tesseract OCRへ渡す機能を追加。
- OCR画像は指定倍率で拡大し、軽いグレースケール＋コントラスト補正を実施。
- OCR結果は行ごとにテキストとconfidenceを表示。
- OCRはTesseract.js 5をCDNから読み込むため、初回は通信が必要。
- DB照合・誤認識補正・装備名正規化は次段階。
