# MH Wilds OCR — Step 1.25-C v4.0.0

DBアイコンアンカー統合・適応型OCR版。

## 目的
過去の Step 1.25-B v3.1.2 の適応型OCRエンジンを維持し、前段にDBアイコン検出を追加する。

画像 → DBアイコン検出 → アンカー右下 → 9行グリッド生成 → v3.1.2既存OCR → 候補統合/DB照合

## v4.0.0の変更
- タイトルを Step 1.25-C v4.0.0 に刷新。
- 3枚のDBアイコンを自動ロード。
- アイコンテンプレートマッチングでアンカーを検出。
- メイン→頭の2段ピッチ、胴以降の防具ピッチを使って9行を復元。
- 生成した9行を既存v3.1.2の装備名OCRへ渡す。
- 既存の複数前処理、OCR候補統合、装備部位別DB照合は削除・簡略化しない。

## 検証
1. index.html をSafariで開く。
2. スクショを読み込む。
3. 「DBアイコンアンカー→9行生成」を押す。
4. 9行の座標とOCR帯が正しいことを確認する。
5. 「装備名を一括認識」を押す。
6. OCR結果とDB候補統合を確認する。
