# MH Wilds OCR — DBアイコン照合検証 v0.1

DBに登録したアイコン画像をスクリーンショット内からマルチスケールで照合し、検出したDBアイコンの境界を基準に右下角アンカーとOCR帯を可視化する独立検証版です。

- 文字OCR・カテゴリ文字には依存しません。
- DBアイコンをスクリーンショット上の検出サイズに合わせて描画します。
- 右下角をアンカーにし、アンカーYを中心にH/2上下のOCR帯を表示します。
- サンプルDBアイコンは検証用に実キャプチャから切り出したものです。最終版ではクリーンなDBアイコンへ差し替えます。
- OpenCV.jsをCDNから読み込みます。
