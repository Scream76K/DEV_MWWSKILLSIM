# DEV_MWWSKILLSIM OCR Step 1 — メイン武器

これはシミュレータ本体とは分離した、OCR開発用の第1段階です。

## 絶対条件
- 装備画面には武器が2種類ある。
- 上段＝メイン武器。
- 下段＝サブ武器。
- 今回のシミュレータへ反映するのは上段のメイン武器だけ。
- 下段のサブ武器はOCR候補として扱わない。

## 今回やること
1. 装備スクショを読み込む。
2. メイン武器名だけを含む領域を赤枠で切り出す。
3. その領域だけをTesseract.jsでOCRする。
4. 画面全体OCRは行わない。
5. まだMHDB照合やシミュレータ反映は行わない。

## 合格後
このStepで領域が確立できたら、次に「メイン武器OCR → MHDB候補照合」を追加する。
その後、防具→珠→スロット整合性の順に進める。

## 注意
初期の赤枠は仮のキャリブレーション値です。今回の実スクショで赤枠が正しくメイン武器名だけを覆うことを確認してから次段階へ進みます。
