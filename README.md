# MH Wilds OCR v4.5.2

## 今回の修正
- v4.5.1で発生していた装飾品OCRの「全19件が装備グループ1 / 1番スロット」問題を修正。
  - グループ生成時に `groupIndex` / `slotInGroup` を元ROIへ書き戻す。
  - OCR結果とグループ/スロットの論理IDを同一ROIで保持。
- 装飾品DB照合を強化。
  - 現在のDB規模（約361件）では、候補漏れを避けるため全件を対象に編集距離で評価。
  - 期待スロットLvと武器/防具種別をハード条件として使用。
  - 条件に合わない別スロットへフォールバックしない。
- 装備OCRの既存復旧経路は維持。
  - DB取得はOCRと並行。
  - OCR未認識時にDB候補を捏造しない。
  - 武器/防具/護石DB、キャッシュを維持。
- 装備OCRの成功しているv4.5.1の前処理・判定ロジックは極力変更していない。

## 重要
この版では、装備OCRそのものを別方式へ全面変更していません。v4.5.1で改善した装備OCRを土台として、今回確認された装飾品グループ接続とDB照合の不具合を先に修正しています。

## 構文検証
Node.js `--check` によるJavaScript構文チェック済み。
