# MH Wilds OCR — Step 1.25-C v4.0.5

DBアイコンアンカー方式と、v3.1.2で確立した装備名OCR前処理を統合する検証版。

## v4.0.5の目的

前処理アルゴリズム自体は変更しない。以下の5方式を維持する。

- 白文字強調
- 白文字・色除去（HSV）
- グレースケール
- 局所コントラスト＋軽いシャープ（救済）
- Otsu（救済）

変更点は、DBアイコンから確定した装備名帯を **元画像から直接クロップ** し、その生ピクセルを一度だけOCR用サイズへ拡大してから、既存の前処理へ渡すこと。

## 入力画像生成

1. DBアイコンを検出
2. アイコン右下をアンカーとして9行を復元
3. 装備名帯を確定
4. 元のHTMLImageElementから直接 `drawImage` してOCRキャンバスを生成
5. 実際の字高をアイコン高さ由来のUI比率から推定
6. 目標字高約40pxになるよう1.5～4.5倍で拡大
7. 既存5方式を適用
8. Tesseract.js PSM 7
9. DB候補統合

## 重要

v4.0.5では新しいOCR前処理方式を追加していない。入力画像生成条件だけを変更しているため、v4.0.4との比較で「前処理そのもの」と「OCR入力条件」を切り分けられる。
