# MH Wilds OCR — アイコン起点テスト v0.3

## 目的
画面全体の汎用候補検出をやめ、装備変更画面で「探す対象の種類と行位置が既知」であることを利用して、対象行の狭い領域だけからアイコン候補を検出するテスト版です。

## v0.3
- メイン武器 / 頭 / 胴 / 腕 / 腰 / 脚 / 護石 / 装衣を既知対象として扱う
- 全画面総当たりを行わない
- 行ごとにアイコン探索領域を生成
- アイコン候補位置を保存
- アイコン起点の右側OCR領域を共通形式で生成
- RARE色判定、形状マスター、DB照合、OCR本処理は未実装

### 注意
探索X・Y、行間隔、アイコンサイズは画面レイアウトに合わせて調整するテスト用パラメータです。
