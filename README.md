# MH Wilds OCR v4.6.6

## 今回の変更
- v4.5.12のOCR・装備候補・装飾品グループ判定をベースとして保持。
- 既存のDB取得ローダー自体は再実装せず、そのまま利用。
- 武器 / 防具 / 護石 / 装飾品DBへのアクセスを `MHWildsDataRepository` に集約。
- OCR処理からDB取得処理を直接呼ばない構造へ整理。
- `ensureEquipment()` / `ensureAll()` を共通入口として追加。
- 既存UIの装飾品DB取得ボタンもRepository経由に変更。

## 保全したルール
- 装飾品グループは物理的に8グループ：メイン武器、サブ武器、頭、胴、腕、腰、脚、護石。
- サブ武器は物理グループとして保持するがビルド反映対象外。
- 装衣には装飾品スロットを設定しない。
- 装備スロットLvは「装着可能上限」であり、装飾品Lvとの一致条件にはしない。
- 装飾品OCRで認識した実Lvは、スロット上限以下であることだけを検証する。
- 装備OCRの標準パスを救済OCRで上書きしない。
- v4.5.12のα/β/γ判定修正を維持。

## 目的
今後、DB・OCR・グループ解析・ビルド反映を個別オブジェクトとして分離し、β版で確立した資産を再利用できる構造へ段階的に整理するための基盤版です。
