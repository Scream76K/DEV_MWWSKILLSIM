# MH Wilds OCR Step 1.25-C v4.3.1

アイコン検出方式を再設計。

- DB一致検索は検出段階で使用しない
- 左30%から暗色コアの連結領域を個別検出
- 周辺の色付き領域でアイコン候補を絞る
- X列はピッチではなく候補数最多の列を採用
- 行間ピッチは使用しない
- 同一スクショ内のアイコンサイズは検出列のコア中央値から1つのUIスケールとして推定
- 検出後、DBアイコンから共通フレーム/core geometryを取得
- 右下角をアンカーとしてOCR領域を生成
- 9個に満たない場合も候補をそのまま表示し、強制的に9行を生成しない

まずは同じスクリーンショットで赤枠（推定アイコン外枠）が実アイコンに重なるか確認する。
