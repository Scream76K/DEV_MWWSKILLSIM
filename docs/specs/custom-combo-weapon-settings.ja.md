# 指定コンボの武器別詳細設定

2026-11-25の累積候補（計算の参照ゲーム版 `1.042.00.02`）の現行仕様。承認記録と実装が示す範囲だけを記載する。**実装済み**は該当経路が接続済み、**一部**は技・組み合わせ・経路に制限あり、**設定なし**は専用設定欄なしを示す。どれもゲーム実機での検証を意味しない。

## 共通契約と3つの入口

| 入口 | 条件の決まり方 |
| --- | --- |
| 現在の指定コンボ | 「指定コンボの火力を計算」は選んだ行順・実行技IDを使用。「詳細設定」とその「武器の設定」は初期状態で折りたたみ。行の溜め欄、発動済み状態の専用欄、共通の詳細上書きはそれぞれ別の入力。空欄は、根拠のある経路だけで技・武器別の開始値を補う。明示したOFF・0は空欄として補完しない。 |
| 名前付き保存・読み込み・比較 | 行順と実行技IDを保存し、対応済み条件は保存側から復元する。従来の武器状態欄と「武器の設定」の上書きは別。汎用の上書き欄の名前保存・再読込・比較への適用は**チャージアックスのみ**。大剣・弓の行別溜め、狩猟笛の開始旋律、スラアクの斧強化は各専用の保存契約を持つ。保存側の条件を適用する経路で編集中の値を混ぜない。比較・読み込みで保存バイトを書き換えない。 |
| 標準比較 | 技行がない場合は武器ごとの標準プロファイルを使う。指定コンボ専用の上書きは参照しない。既存の標準向け条件や武器・弾・対象部位の適用ゲートは維持。ライトの標準弾比較には専用経路がある。 |

通常・最大は、同じ技ID、順序、開始条件から独立に評価する。最大側に条件付きスキルがあれば、計算結果は異なり得る。ユーザー向けの主結果は**正規化しない実ダメージ**。最大の増減率は**同一ビルドの通常火力**を分母に `(最大 − 通常) / 通常 × 100` で求める。物理・属性等の内訳も同じ成分同士で比較する。通常が0または未算出なら、増減率は「—」。算出できないダメージは理由付きの「未算出」で、0に置き換えない。選択した基準ビルドの通常を100とする旧方式の値は互換用の出力・診断に残るが、主結果や最大の増減率には使わない。所要時間の根拠がなければDPSは未算出。

「モンスター・部位設定」は初期状態で折りたたみ、初期対象はトレーニングルーム／正面。武器や技の採用条件外を、初期値で成立した扱いにはしない。

大剣・弓の対応行だけに溜め段階を表示し、初期値はLv3。値は各行の実行技IDに含め、段階を別フィールドに重複保存しない。並べ替え・保存・読み込み・比較で同じ順序と段階を使い、通常・最大の実行技表示に反映する。未知のIDを別段階に読み替えない。弓の追加欄または技行で「剛射」を明示選択すると、正規の溜め3（`canonical:BOW_POWER_SHOT_3`）を表示する。溜め1・2への変更は同じ行で行う。旧保存・プリセットの `bow_spread` は段階不明のまま復元する。

## ビルド火力比較の表示

- 火力表の直上に「計算に使用したコンボ」をコンパクトに表示する。並べた候補ではなく、実際に通常・最大の計算に使用した技順を示す。現在の指定コンボでは、溜め段階の前提や指定した開始条件があれば同じ表の前に添える。使った技を確認できない経路では推測で補わない。
- 火力表の最下段に、合計に含めない固定ダメージを発動1回あたりの注記として表示する。通常・最大で内容が同じなら1回だけ記載し、異なる場合は区別する。注記の数値は火力合計や増減率に加えない。ビンなど、採用した計算式に含まれる武器固有の成分は別であり、火力の内訳と合計に残す。
