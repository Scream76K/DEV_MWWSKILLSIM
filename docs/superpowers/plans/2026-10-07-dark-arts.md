# Dark Arts reference calculation implementation plan

Goal: calculate the separate great-sword wave from source-confirmed values without changing unresolved whole-build indices.

Architecture: store wave motion/dragon values once in the canonical Technique DB; a small reference module reads them through TechniqueDBEngine. Expose a manual reference panel after the existing advanced reference panels. Automatic HP/DPS inclusion remains pending until conditional body element, target dragon hitzone and all interacting buffs are handled.

Constraints: no guessed hit timing; no weapon-element substitution for the fixed dragon wave; source confirmation is not live verification; do not change comparison column widths.

- [x] Add failing tests for wave physical/dragon separation, crit, sharpness, dragon strengthening, invalid input and source gates.
- [x] Register the dedicated wave record and implement a reference-only calculator, with explicit counts rather than inferred combo procs.
- [x] Add a collapsed manual panel with empty required inputs and invalidate stale results on edits.
- [x] Test DOM controls and mobile browser layout, run inherited tests, package the full release.

Review focus: missing numbers must not become zero; dragon hitzone must be independent of weapon element; negative crit affects physical only; zero dragon hitzone remains pending; dedicated special record cannot be treated as an ordinary weapon-element hit.
