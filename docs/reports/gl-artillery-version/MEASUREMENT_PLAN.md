# ゼーリエ判断用：砲術の最小測定案（実施未承認・未依頼）

現行版への数値・順序・技別火加算の適用を確定するための案。既存動画に下記条件が揃えば再撮影は不要。ゼーリエが必要性を判断してから実施する。

## 条件を固定する

- ゲームの版番号を画面で記録（計算基準1.042.00.02との一致/不一致を明示）。
- 通常型ふつうの同一武器。候補ホープガンランスⅠ等。武器詳細で攻撃・会心・砲撃タイプ/力・強化/生産/復元条件を確認。
- 会心・斬れ味は砲撃へ乗らない仮説を使用するが、値と状態は記録。
- 料理・装衣・オトモ・旋律・根性等の攻撃補正と未照合追加ダメージを外す。スキル全一覧を撮影。各比較で指定スキル以外を変えない。
- 同じ訓練対象/部位。火肉質が版付き根拠で分かる部位を使う。30や0を未確認のまま前提にしない。火肉質不明なら先に根拠確認。
- 装填を毎試行戻し、全弾命中。リロードを計算する実験ではない。

## 順序（必要な群だけ実施）

A：通常砲撃1発、砲術0/1/2/3の4条件。他の攻撃スキルなし。倍率/火加算の現行版一致を確認。
B：通常砲撃1発、砲術0/3それぞれで「既知の加算だけの攻撃スキル」と「乗算+加算を持つ既知の攻撃スキル」を装備。効果値はMHDB/既存確定表で確認、攻撃力表示も記録。加算分まで砲術で乗算する式と、加算を後置する式を区別する。Aの砲術0/3を基準として利用。
C：砲術0/3、溜め砲撃1発/2発、満装填FBを各々比較。Hitカウンターと総ダメージを記録。物理強化が火加算にもかかるか、加算がHitごとか技全体1回かを分離する。
D：A～Cに矛盾がなければ放射/拡散でも砲術0/3の通常砲撃を確認。全型全レベルの撮影を初めから要求しない。

## 撮影内容

ゲーム版、武器詳細、装備スキル一覧、攻撃力表示、対象/部位、試行前装填、各技の実ダメージ/Hit数を識別できる画面または連続映像。保存ファイルのパスと各条件の時刻を記録。静止画だけでHit内訳が不明なら該当攻撃の短い動画を使用。

DPS・時間・フレーム係数の採用は対象外。測定値をMV/固定値へ直接登録せず、条件付き成分式との整合を先に評価する。
