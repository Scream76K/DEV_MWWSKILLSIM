# 原著砲術：Hit・成分単位の設計提案（2026-10-12）

## 結論

武器/技全体の倍率を総ダメージへ掛けず、Technique ID→イベント/Hit→物理/火成分に適用対象を持たせる。数値はTechnique DBのみを正本とし、UI/Handlerへ重複定義しない。
今回の原著はVer1.000.05.00。GameWithは2026-06-01更新だが実測対象ゲーム版の明記なし。両資料の一致は現行VERIFIEDの根拠ではなく、暫定採用候補の補強とする。今回は調査/提案のみ、製品DBへの新採用なし。

## 旧Hit実測の記録とDB境界

HISTORICAL_HIT_EVIDENCE.jsonへ対象版/条件/Hit別物理/火を記録。HBG竜撃弾は旧1Hit目物理168→184.8/201.6/218.4、火12不変、旧2Hit目物理39.9/火6が不変。これらは基礎攻撃210の旧条件下の実測由来であり、本番の固定ダメージ値ではない。
重要：現在のHBG_WYVERN_AMMOはimpactValue1、explosionValuePerHit32.2、fireValuePerHit50、explosionHitCount5という構成。原著の旧2Hitと一致しない。旧Hit番号を現在DBの第1爆発/第2爆発へ機械的対応付けしない。版差/イベント意味を照合するまで未算出。
LBG旧0.5物理補正は原著が整数MV仮定から推定した値で、現行採用値として追加しない。旧MV25/32/40等も現在のSOURCE_CONFLICTを上書きする根拠にしない。

## 共通管理の提案

各適用ルールにweaponType、Technique ID、event/component ID、Hit番号またはイベント種、ビン/弾種、状態条件、物理倍率、火表示加算の可否/単位、対象版、source URL、暫定/検証状態、未確定理由を持たせる。
「適用しない」は根拠付き非適用として記録し、未確認と区別する。火成分不明を0にしない。GL火表示+30は内部換算前の加算であり、全攻撃の最終火ダメージ+30ではない。
CBはBODY_SLASH、IMPACT_PHIAL_EXPLOSION、POWER_ELEMENT_PHIALを独立。新砲術候補はIMPACTだけ。KAN-21の5本強属性SAEDと盾1.3の扱いを変更しない。
徹甲はINITIAL_IMPACT、EXPLOSION_PHYSICAL、FIREを独立。着弾の砲術適用を爆発測定から推定しない。
GL FBは複数砲撃イベントの列として評価し、砲術候補の適用とFB固有物理倍率/火加算順序を別ルールにする。未知成分があれば総量未算出。
時間短縮は独立したtimingEffectの旧版証跡に置き、P0合計・倍率・Hit数へ混入させない。

## 推奨採用順

1. 現在のGL通常砲撃・neutral条件限定を維持し、現行版への断定をしない。
2. CB榴弾/徹甲爆発の倍率を成分限定の暫定候補として扱う。イベントと基礎式が既存DBで成立する技だけ、承認後に接続。今回本番採用なし。
3. HBG竜撃弾は旧2Hit記録の保存を優先。現DB5爆発との対応と版差が揃うまで現行ルールへ接続しない。
4. 通常攻撃スキル順序、溜め/FB火加算、竜熱相殺弾は根拠待ち。技一覧だけで完成扱いにしない。
