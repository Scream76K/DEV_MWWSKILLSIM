## 2. 通常攻撃スキル・砲術の計算順序比較

B=stats.attackComponents.weaponBase、M=normalMultiplier、F=normalFlat、H=未採用の砲術倍率、C=技物理係数×技別倍率とする。これは比較用の記号であり数値DB/実装ではない。

|経路/資料|順序|状態|
|---|---|---|
|現calcBuild|attackTrue=B×M+F|コードで確定。Bは通常スキル計算前、Artiaでは完成固定値と復元加算を含む|
|現砲撃Handler|物理=B×C、武器属性/会心/斬れ味を混ぜない|コードで確定。M/Fは渡していない、砲術装備時は全体保留|
|旧原著の式|(B×M×H+F)×C|旧版参考。加算Fまで砲術で乗算しない。資料自身が1.011以降旧情報と明記|
|単純なattackTrue乗算案|(B×M+F)×H×C|旧式とはFの扱いが違うため、砲術を最後に掛けるだけでは順序が確定しない|
|現行kuroyonhon技能表|攻撃スキルの掛け算段階で適用と記述|明示ゲーム版/加算前後の現行実測が不足|

重要な境界：現在のGL共通参考は通常攻撃スキルのM/Fを使わない。砲術倍率だけ追加しても通常攻撃スキル込みのビルド反映を解決しない。現行仕様が未確認なので製品不具合と断定せず、GL_ATTACK_SKILL_ORDER_PENDINGとして次の接続判断へ保持する。攻撃スキル付き実装備の完全対応を宣言しない。
復元で確定済みの加算と一般スキル加算Fを一律に扱わない。KAN-19の完成固定値へ進化/生産補正を二重加算する変更は行わない。

## 3. 型・アクション別の既存採用条件

|型|既存基本装填数|通常物理倍率|溜め物理倍率|FB物理倍率|
|---|---:|---:|---:|---:|
|通常|6|1|1.8|1.4|
|放射|3|1|1.8|1.4|
|拡散|2|1|1.8|1.35|

これはTechnique DBの暫定採用値の整理。現行版実機VERIFIEDではない。対応するGL_SHELL_*_MEDIUMレコードから物理係数/火値を取得し、コンボへ重複定義しない。
通常は1弾消費、溜めは明示した消費弾数/Hit数、FBはその時点の残弾全消費。自由コンボは逐次消費し、自動リロードを仮定しない。弾不足/欠損/未対応補正なら部分和を総量として出さない。
実武器の既知shellタイプは指定と照合、shellLevel2→MEDIUMだけ接続。既知の他段階をMEDIUMへ上書き不可。メタデータ欠損は共通参考UNVERIFIEDの範囲であり実武器検証ではない。
砲術/砲弾装填/食事等の未照合補正は全3経路保留。選択部位の火肉質を優先し欠損は保留。通常竜杭/集中竜杭/竜撃/竜杭FBを通常FBに混ぜない。

## 4. 砲弾装填

公式MHDB生成元Skill.jsonのgame_id802725120：Lv1は弾/ビン装填速度、Lv2はさらに装填速度とGL装填数+1。kuroyonhon技能表にもLv2+1を確認。これは資料一致の確定事項であって現在ゲーム版実測VERIFIEDとは別。
基礎容量へ+1を採用する場合の算術上容量は通常7/放射4/拡散3。砲撃係数/MV/火値を+1する意味ではない。開始残弾を自動で最大へ増やす意味でもない。CBの最大5ビン前提は変更しない。
現コードはLv1/2とも保留リストに含む。Lv1は時間対象外のP0では影響しない候補だが、今回開放しない。Lv2も容量増分/保存条件/実武器との対応を実装前に整理する。Artiaの斬れ味復元値+30等をGL弾数増加とみなさない。
