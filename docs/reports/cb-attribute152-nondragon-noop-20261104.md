# チャアク属性変換152 — 非龍属性の直接火力へ加算しない限定修正（2026-11-04）

## 基点と受入範囲
基点 `b4ece1bef87da2dc27c92245c5d63b409603e956` の `flamme/cb-bladescale-first-hit-candidate-20261104`。候補ブランチ `flamme/cb-attribute152-nondragon-noop-20261104`。未承認拡張（雷耐性変換165・刃鱗研装163）も基点に含まれるため、本件の成功のみで全差分の正式採用を認めない。

根拠：[GameWith 属性変換（2026-09-08更新）](https://gamewith.jp/mhwilds/487426) — 龍属性以外の武器に龍属性攻撃値の上昇効果なし。別途蓄積による龍属性追加ダメージがあるが、このシミュレーターの固定コンボ直接火力には固定ダメージ/発症効果を含めない。

## 製品候補修正
`hope-hammer-browser-adapter.js` の152適用範囲を分離。
1. 適用状態の明示 `normal/maximum` はこれまで通り必須。Lv1～3、出典付きルール検証も維持。
2. `elementType !== 'dragon'` では龍属性攻撃値の増加効果を追加しない。必要な龍属性キャップ処理も適用しない。これにより非龍属性で最大側152がONでも計算を停止させず、計算値を増やさない。
3. `elementType === 'dragon'` は既存の範囲チェック・キャップ処理・属性効果付与を維持。複合技・追加Hitの非対応判定は無条件解除しない。
4. 蓄積・追加龍属性ダメージは直接Hit計算には導入しない。
