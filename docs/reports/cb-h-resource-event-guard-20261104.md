`tools/cb-h-power-component-audit.cjs` に公開 `calcBuild()` の `routes.H.channels.normal/maximum.diagnostics.resourceContracts` を使うイベント別assertを追加。実MHDB103 ウズ・ヴァレロヤⅡ、訓練場正面、R/H独立開始、Hの斧強化ON・盾強化ON・剣強化OFF、開始在庫2条件で確認。
