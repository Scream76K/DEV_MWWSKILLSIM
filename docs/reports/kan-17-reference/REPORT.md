## 実装した最小変更

evaluateComboRouteで、全技のダメージと正の有限所要時間が揃う場合だけ referenceDps=damage/time を追加。referenceDpsStatus=PROVISIONAL_REFERENCE。欠落成分/技/時間はBLOCKED/TIMING_PENDINGとしてreferenceDps:null。既存theoreticalDps/practicalDps/dpsおよびVERIFIED条件・異武器種比較制限は維持。稼働率や1分期待値へ変換しない。

単体calcDps、dpsForStats→compareSnapshot→比較JSON、コンボ検証レポートに追加フィールドを伝播。単体/比較は「コンボDPS（暫定・参考）」を正式DPSと別表示。既存schemaVersionやpowerIndex/relativePowerIndexを変更しない。旧キャッシュのDPSを暫定値として自動採用しない。属性欠損時のキャッシュ参考値もJSONで除外する。

今回Technique DBの数値/検証状態は変更なし。既存のTechnique DBダメージ評価・登録参考時間を使用し、時間を推測しない。ユーザー登録技・時間は従来の明示登録範囲で扱い、資料検証済みに昇格しない。技別詳細・保留理由に加え比較診断にtimingStatus/timingEvidenceを伝播する。
