# 固定ダメージ系スキルの評価指標方針

オーナーの最新確定回答により、灼熱化71は固定部分と火属性部分の両方を、基準/最大の数値火力へ含めない。注釈のみ。以前の『最大へ固定+火を一度合算』『火属性だけ最大へ』案は撤回済みで、製品へ一度も実装していない。回数/Hit時刻/確率期待値を入力・生成しない。

全スキル監査の分類に「固定ダメージ系・注釈のみ」を追加する。現在確定適用行は灼熱化71。他の混合効果で通常攻撃バフまで消す根拠にはしない。武器固有の砲撃・ビン・HH固定成分等はこのスキル除外方針の対象ではない。効果の存在は認めつつ指標から除外するため、「火力非対象」や「未実装」と別分類。

実装：index.html:standardGroupPowerPlanが71のparent/name/rank/部位数を検証、ScorchReference.damageの既存係数から上位の注釈値を取得する。固定/火肉質を計算結果へ加算せずannotationOnlyで保持。未知rank/不正部位数/重複は通常の未解決経路を維持。

Adapterは診断excludedSkillDamageへ伝達。index.html:excludedSkillDamageDisplayを単独renderSummaryと保存比較表示が共用する。新保存フィールドなし、保存装備の再集計で同じ方針を得る。比較表示の呼出は静的確認、今回保存AB実行をした意味ではない。

最小契約確認：スキルなし/灼熱Ⅰ/Ⅱすべて通常最大375.73で不変。Ⅰ注釈は固定20+火表示600、Ⅱは40+1200。両成分の除外と単独DOM注釈をassert。tools/skill-scorch-annotation-proof.cjs、scorch-annotation-after.json。合法実装備・実機・発動頻度の検証ではない。

黒蝕106のrank/状態/攻撃/克服会心モデルは別途承認済み。現時点は実装接続前であり、本注釈方針へ移していない。新しい承認待ちではなく、次の実装作業として残る。

## 最終補足の反映

属性値を使う注釈計算も許可。Adapterは既存ScorchReference.damageへ現在の火肉質と火属性強化Lvを渡し、追加ダメージ内訳をdiagnostics.excludedSkillDamage.additionalDamageへ保持。上位資料限定、他バフなしの注釈であり火力へ加算しない。入力不明/未対応肉質は注釈のみ不明、本体を止めない。表示は単なる600/1200ではなく算出した追加ダメージを示す。

最小確認：火肉質30%でⅠは20+18=38、Ⅱは40+36=76と注釈表示し、本体通常/最大は375.73のまま。火肉質未取得ケースでも本体375.73、注釈のみ不明。比較表示は同じformatterへ静的接続、今回保存AB実行なし。

## 全スキルへの一般化

固定MHDB179行の原文から、スキル自身の追加ダメージを抽出。①通常の攻撃力/会心/属性上昇、②状態異常蓄積・爆弾アイテム、③武器技固有の追撃とは区別した。

共通正本：index.html:SKILL_EXTRA_DAMAGE_POLICIES。通常スキルはAdapter.annotationPolicyでID/name/Lv照合。seriesはstandardGroupPowerPlanでparent/rank/部位数/重複を照合し、追加成分だけannotationOnlyとする。計算式がない注釈を0としない。旧STANDARD鎖刃刺撃pendingも追加ダメージだけの指標除外方針に従い停止させない。

蒼雷一閃の最大会心は既存calcMaxAffinityの単一hasSkill分岐へⅠ/Ⅱ名を追加した。+15を別L3効果に重ねていない。基準は非発動の既存契約。現在の一般化は外部発動状態全般の新機能ではない。

共通diagnostics.excludedSkillDamageを単独と保存比較の共通formatterへ伝達。計算できた注釈/不明な注釈のどちらも数値総計へ加算しない。属性変換の既存『本体限定参考』表示・適用制限は残るため、これを全属性対応Doneとはしない。

最小契約確認extra-annotation-after.json：鎖刃Lv5/白熾/鏡刃/恨撃Ⅰは通常最大375.73。蒼雷Ⅰは通常375.73を維持、最大のみ既存会心効果で増加。追加ダメージのcomponent生成なし、注釈不明あり。単独DOM確認、保存比較は同じformatter呼出の静的確認のみ。今回新規注釈係数は採用していない。
