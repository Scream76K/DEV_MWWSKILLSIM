## Narrow boundary

The new IDs are eligible only when rapidAmmoSequence is the validated LBG_FIVE_ROUNDS_25_HITS policy. The explicit single-trigger route retains its previous skill scope. Exact ID/name/rank validation, resolved condition plan, no pending entries, and adopted bonus restrictions remain required. Peak Performance additionally requires exactly one matching applied row, as the existing common attack-flat skill does.

First/Force effects remain NOT_APPLIED and visibly partial. Unknown skills/health conflicts are not made supported by this change. Continuation may still omit a conflicting effect and calculate the supported subset; that must not be described as simultaneous full-health and low/recoverable-health adoption.
