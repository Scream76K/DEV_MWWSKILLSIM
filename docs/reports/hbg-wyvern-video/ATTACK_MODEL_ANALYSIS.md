内部攻撃候補 A=B×mA+fA+K。
初段 D1=0.8×(B×mA×mR+fA+K)+(400/10)×H。
次段 D2=0.19×A+((200×mF+fF)/10)×H。

初段砲術対象P=0.8×B×mA。砲術非対象C=0.8×(fA+K)+40H。初段火強化は観測組合せで不変なので式には含めない。次段には砲術を掛けない。全攻撃/火強化状態の適用範囲が確定したことは意味しない。

## 競合式・丸め候補

1. バフKを攻撃スキル倍率にも掛ける式 A=(160+11)×mA+fA は初段Lv4=157.936→157.9、Lv5=161.472→161.5。実測157.8/161.1と不一致。
2. 初段集計攻撃A全部へ砲術を掛ける式0.8×A×mR+12は攻撃0砲術2=176.16→176.2（実測174.4）、攻撃5砲術2=190.944→190.9（実測187.7）。固定加算の非対象が必要な候補。
3. 内部攻撃をダメージ前に整数切捨てする式はLv4=157.6/Lv5=160.8で不一致。表示攻撃の整数値を計算へ戻すのもLv5不一致。
4. 最終ダメージ小数1桁の最近傍丸めは全点整合。切捨てはLv4=157.7、次段Lv0=38.4で不一致。ただし成分ごと丸め→加算でも今回値では一致する例があり、丸め位置/内部精度は一意に確定しない。Decimal ROUND_HALF_UPは検算上の仮定。ちょうど半端の観測がないため四捨五入方式のタイ規則も未確定。

kuroyonhon一般計算説明 https://kuroyonhon.com/mhwilds/d/dame.php は基礎×倍率後の加算と小数保持を記載し、本候補と方向は整合。ただし竜撃弾専用の演算順序を直接確認したわけではない。非属性弾の火強化非適用という一般記載と今回の次段火強化は例外/版の照合未完（前報告参照）。
