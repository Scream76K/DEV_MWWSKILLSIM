# 通常アーティア近接の白前提

Owner 2026-10-25 22:35 UTC: 「通常アーティアは切味白です」。通常Ⅰ/Ⅱ/通常rare8の明示登録された近接のみ。最大色指定でありゲージ長、消耗、実ゲーム検証を意味しない。巨戟・遠隔の扱いは変更しない。

既存 weapon-max-sharpness.js の白物理1.32・属性1.15を参照。原典sharpnessを改変せず、装備投影にMAX_COLOR_ONLYの根拠を保持し、共通resolverへ渡す。通常近接sharp:Iは白を維持しゲージ長未計算として許容。他の未対応復元は拒否維持。

## 最小実行証拠
MHDB303（保存済み原典、青40/白0）、水、無スキル、既存大剣3技。復元なし/斬れ味Ⅰの2状態。攻撃185・属性330を維持、各通常/最大1045.69、実表示1045.7。過去青の同入力に対して各物理Hitは1.32/1.20、各属性Hitは1.15/1.0625の差を丸め誤差内で検証。計算結果・集計の上書きなし。保存比較の追加実行なし。実行ベースf7b535db5459c314746e9f2300885a818327d1bdと未コミット製品2ファイルのSHA256をresult.jsonへ保存。

初回ハーネスは空の復元配列にUI選択肢を期待して失敗。実UI同様の5枠へ修正し、結果参照もchannels.componentsとcomponent idへ訂正。初回ログを保持。旧検証器は変更していない。自動承認レビューが旧検証器上書きの懸念で最初の新規証拠作成を拒否したため、旧ファイルの差分なしと新規ファイル不存在を確認し、提案された一時ファイルで検証した。

## 装填復元の説明と未実装
資料 https://kuroyonhon.com/mhwilds/memo/38.php の復元ボーナスには装填数強化（+1、最大2回）がある。https://www.phantombrawlers.com/mhwilds/Artian のCapacity Boostはボウガン限定、弾種別の制約を伴う。これはCBの砲弾装填スキルでも、同属性生産素材による属性弾装填数でもない。

既存renderArtiaの巨戟共用UIはsharp:I / sharp:EXを「斬れ味・装填数強化Ⅰ +30 / EX +50」と表示するが、restoreStatsはsharpに30/50を足す。これを弾数とする実装根拠はない。共用表示は誤解を招く既存課題であり、+30/+50発と説明してはいけない。今回装填数強化の新規採用/有効化なし。通常ボウガンsharp:Iは引き続き未対応として拒否。
