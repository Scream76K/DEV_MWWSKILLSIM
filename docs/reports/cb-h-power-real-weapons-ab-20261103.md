# CB強属性H — 異なる実武器の保存比較・復元実証 (2026-11-03)

## 位置づけ
基準: `flamme/cb-power-phial-components-20261103` の `6be565f8da8d2ef8069f72513832328a594f414d`
作業: `flamme/cb-power-h-real-weapon-ab-20261103`
**H強属性は隔離検証候補であり、正式製品では `CB_H_IMPACT_ONLY` が維持される。** 本件は公開 `calcBuild()` をJSDOMで呼び、テスト実行時のHTMLメモリ内だけH強属性のゲートを除外した。DB・計算式・ビン係数・製品ソースは無変更。

## 実装内容
`tools/cb-h-power-real-weapons-ab-proof.cjs` でMHDBの実武器103・104を同時登録し、R/H独立AXE開始、盾ON、斧強化ON、剣強化OFF、H開始強化ビン0.5＋通常ビン0.5で算出・保存・読込・A/B比較・状態復元を実施。組み合わせのHit/MV/属性補正は既存Technique DB正本を再利用。

| | MHDB103 ウズ・ヴァレロヤⅡ | MHDB104 ウズ・ヴァレロヤⅢ |
|---|---:|---:|
| 基礎攻撃 | 190 | 220 |
| 表示水属性 | 260 | 320 |
| 通常R/H合計 | 1977.365999999999 | 2564.692 |
| 最大R/H合計 | 1977.365999999999 | 2564.692 |
| 保存→個別復元→比較 | 一致 | 一致 |

両武器は通常と最大に同一計算条件を採用したため、両チャネルの結果が一致。比較の各行が単独計算の丸め前の実値と一致し、比較前後で現在のビルドおよび保存mapは変化しない。両武器とも計算に必要な資源は独立開始条件として保持される。

## 失敗と是正履歴
- [初回CI](https://github.com/Scream76K/DEV_MWWSKILLSIM/actions/runs/41636518291)：試験コードがDBへ「最後に選択した1武器」だけを登録し、最初の保存武器を正しく復元できなかった。
- [2回目CI](https://github.com/Scream76K/DEV_MWWSKILLSIM/actions/runs/41636674884)：両武器をDBに保持して実数値復元成功。残る差分はテストfixtureが護石スキルを空配列にしていたのに対し、読込UIが名前空欄の3スロットを生成したことと、weaponSlotの空値→false正規化。
- [最終CI](https://github.com/Scream76K/DEV_MWWSKILLSIM/actions/runs/41636876933)：空欄護石は「名前付きスキルなし」という意味でのみ正規化し、実スキル名・レベルや装備・武器ID・実計算値・保存の不変性をassert。全関連ステップ成功。

## 境界
- H強属性の盾突き爆発1Hit、消費0について、榴弾限定HのOWNER_APPROVED_PROVISIONALを強属性に自動拡張しない。
- 確認済みはJSDOM・MHDB実武器2件・既存計算式を用いた隔離経路。Safari、ゲーム内再現、全武器・全スキル組合せの保証ではない。
- 斧強化OFFで強化ビン0.5と通常ビン0.5を跨いで1本消費する爆発成分は未採用のまま。
- 全CBの「未算出ゼロ」、正式統合、β公開の完了を意味しない。
