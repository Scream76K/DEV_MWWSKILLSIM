## ローカル履歴とスクリーンショット由来の限界

ARTIA_FIXED_VALUE_R17.md:3–7は「激化タイプ別完成ステータスを正本、進化差分を再加算しない、復元を後段」とする実装方針。生産15込みを実測したとは書かれていない。先の報告でr17を生産込みの数値根拠のように扱った点を訂正する。git上の導入はfea3e7d Add files via uploadで、個別実測由来はこの文書から復元できない。

ARTIA_EVOLUTION_DELTA_FIX_R16.md、ARTIA_MUTATION_DATA_v2.json、ARTIA_FIX_MANIFEST_v1.jsonは激化差分の採用記録。固定素材分の包含を証明しない。

SALADA_REVIEW.mdはユーザー提供スクリーンショット①〜⑤を照合したという当時の記録。ただし内容は装備・珠・護石中心で、素材3個込みの武器基礎を読み取れる原画像との対応は今回未確認。docs/reports/kan-19-20/DATA.md:7以降は2026-10-11 HTTP取得由来のMHDB1139/1140/1141値を明記。一方同:43は元動画 https://youtu.be/E5vkLlVN7gI 未視認と明記。今回も映像測定をしていない。

SALADAの232はdocs/reports/kan-19/ANALYSIS.md:52で190+復元42の算術候補。合成統合fixtureも同方式の期待値なので、生産15が不要という独立実測証拠に使えない。既存テンプレは龍へ補正した履歴があるため元映像の水属性値も無条件には転用しない。

## 朝の最小質問案（数値の正誤を選ばせない）

「資料ではMHDBの170/180および巨戟200/180/190を基礎値として、生産の攻撃素材3個分を別段階にしています。この段階分離を現行版未検証の暫定契約として採用し、通常I/IIの復元I接続と巨戟の生産分を是正してよいですか？」

推奨は資料に基づく限定暫定採用。採用を待つ場合だけ、既存の攻撃素材3個製武器を加工屋の武器詳細で確認できるかを聞く。確認対象は武器名/レア度・激化・生産ボーナス・復元一覧・攻撃表示方式/ゲーム版が対応する同一武器。新武器製作や新規大量測定を要求しない。SALADA01なら190+復元42という旧計算と、生産15別の247との差を同条件で識別できるが、232/247のどちらを好むかとは質問しない。
