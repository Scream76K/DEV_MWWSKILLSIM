# Source normalization rule r11

Source screenshots remain authoritative for equipment identity, decoration semantic identity, count, and equipped location.
Canonical spelling is not copied blindly from OCR or human transcription. Before production storage, decoration names must be normalized against the authoritative decoration master/MHDB. If semantic identity is clear but spelling differs (e.g. 反抗 -> 反攻珠), retain source evidence separately and store the canonical master name. If multiple canonical candidates remain, stop and request human confirmation.
