# Monster Hunter Wilds Skill Simulator v7.7.1

OCR開発版 v7.7.0 の護石スロット不具合修正版です。

## 修正
「護石スロット」→「防2-防1」を選択した際に、内部状態へ `[2,1]` が正しく反映されるよう修正しました。

## 確認ポイント
1. 護石スロットで「防2-防1」を選択
2. 防具スロット1が `[2]`、防具スロット2が `[1]` として表示されること
3. 護石装飾品に `[2]` と `[1]` の2枠が表示されること
4. 装飾品をそれぞれ選択できること
5. 護石生成可能性の判定が「防2-防1」として行われること
